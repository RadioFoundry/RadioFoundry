# 按键与导航

每个按键在每个屏幕上都做同一类事情。

## 五条规则

1. **OK** 打开或选择焦点所在的项目。长按 **OK** 执行持久的版本，例如保存或设为永久。
2. **返回** 返回上一级。在主屏幕上，每按一次撤销一项临时更改。长按 **返回** 可从任何位置回到主屏幕。
3. **\*** 打开当前操作的快速设置。长按 **\*** 锁定或解锁按键。
4. **#** 打开焦点项目的操作，例如某个人、通话组、消息或最近来电。在 DMR 信道上长按 **#** 打开通话目标选择器。
5. **PTT** 在任何列表中与焦点所在的个人或通话组通话一次。没有焦点项目时，它与信道的通话目标通话。

大多数屏幕的底行是提示行。它显示最近的几个按键在该屏幕上的作用。**返回** 的作用显示在其右端，位于 **返回** 键上方。

菜单打开时，选中第一个可用的项目。你仍可移到灰色项目上并按 **OK**，查看它不可用的原因。**返回** 会恢复你之前在菜单中的选择。

## 按键参考

按键以其功能命名（[约定](01-introduction.md#conventions-in-this-manual)）。[按键角色](23-radios.md#key-roles)列出你的电台上
哪个物理键承担哪项功能，以及电台没有某个键时由什么代替。

| 按键 | 短按 | 长按 |
|---|---|---|
| **OK** | 主屏幕：打开 hub。列表：打开或选择 | 保存或设为永久 |
| **返回** | 返回上一级。主屏幕：撤销一项临时更改 | 回到主屏幕 |
| **上**、**下** | 移动焦点。主屏幕：下一个或上一个信道（在 VFO 中为一个频率步进），或在设置了 **设置 > 按键 > 主页上下键** 时切换区域或通话目标（信道旋钮仍切换信道）。编辑器：更改数值 | 连续重复 |
| **\*** | 快速设置。在 FM 上用 **PTT** 发射时：该键的[双音多频](08-fm.md#touch-tones-dtmf) | 锁定或解锁按键 |
| **#** | 在 FM 上用 **PTT** 发射时：该键的[双音多频](08-fm.md#touch-tones-dtmf)。其他情况：焦点项目的操作。主屏幕：最近来电的操作。VFO：调谐到正在输入的频率，作用同 **OK** | DMR 信道：通话目标选择器（选择通话组，或输入 ID）。“最近”是 **OK**、**3** |
| **0** 到 **9** | 主屏幕：启动查找。列表：选择编号行，或输入以筛选。VFO：输入频率。用 **PTT** 发射时：在 FM 上发送该键的[双音多频](08-fm.md#touch-tones-dtmf)；在 DMR 上无动作 | 用 **PTT** 发射时：同短按 |
| **上一区域**、**下一区域** | 主屏幕：上一个或下一个区域 | |
| **监听** | FM：按住期间打开静噪。DMR：打开或关闭数字监听（所有通话组） | |
| **通话目标** | 通话目标选择器（DMR 信道） | 同短按 |
| **A/B** | 双守候：切换到另一个信道 | 打开或关闭双守候 |
| **功率级别** | 主屏幕：下一个功率级别 | 按住 1.5 秒：紧急（[紧急](11-emergency.md)） |
| **PTT** | 发射 | |
| 信道旋钮 | 每一格为一步。顺时针：主屏幕上的下一个信道（同 **上**）、列表或菜单中的下一行，或编辑器中更大的值。逆时针：相反 | |

你可以给侧键（大多数电台上的**监听**、**通话目标**和**功率级别**）分配其他功能。在**设置 > 按键**
（[设置](17-settings.md#keys-key-8)）或电台频率中设置。

每次按键都会发出短促的按键音，除非关闭了**设置 > 声音 > 按键音**。

按键锁定时（长按 **\***），**PTT** 仍然可用。**设置 > 按键锁 > 锁定时 PTT** 关闭时，**PTT** 会发出错误提示音，
电台显示“锁定时 PTT 关：长按 * 解锁”。

## 在屏幕间移动

主屏幕是基础。其他所有屏幕距离它最多三级。

```
主屏幕
 |-- *            快速设置
 |-- OK           Hub：1 联系人、2 消息、3 最近、4 区域、5 信道、6 工具、7 设置
 |                    （没有 # 的电台在顶部多出 0 最近来电）
 |-- #            最近来电的操作
 |-- 长按 #       通话目标选择器（DMR）
 |-- 0-9          查找
 '-- 通话目标     通话目标选择器
```

在编号列表（hub、工具、设置、操作、快速设置）中，数字键选择对应编号的行。例如 **OK**、**6** 打开工具。

在长列表（联系人、信道、某个区域的信道）中，数字键按名称筛选列表，方式与手机键盘拼写单词相同。**2** 是 ABC，
**3** 是 DEF，依此类推到 **9**（WXYZ）。每按一个键，列表就缩小到含有以这些字母开头的单词的名称。**返回** 删除你最后输入的键，
然后离开列表。

## 查找

在主屏幕上（VFO 中除外），按数字键打开查找。查找一次搜索所有内容。输入数字。查找按以下顺序列出：

1. 当前区域中该位置的信道。“12”列出信道 12。
2. 把数字当作电台某个频段中的频率，按 VFO 的方式解析：“438250”列出“VFO 调到 438.250”。**OK** 在该频率上打开 VFO。
   VFO 的模式、功率和亚音保持不变。
3. 名称与按键字母匹配的区域内信道、联系人和通话组、区域、位置（联系人、消息等）以及设置。
4. DMR ID 以该数字开头的联系人，从输入三位数字起。
5. 数字本身，作为通话组（“通话 TG 3100”，“未保存”）和作为个呼（“个呼 3100”）。
6. 没有联系人使用该 ID 时，列出“新建联系人 3100”。**OK** 打开**新建联系人**（[联系人](09-dmr.md#contacts)）。

然后使用以下按键：

| 按键 | 作用 |
|---|---|
| **OK** | 转到信道或区域、调谐 VFO、打开位置或设置、暂时与通话组或个人通话，或新建联系人 |
| **PTT** | 与焦点所在的通话组或个人通话一次 |
| **#** | 打开焦点通话组或个人的操作 |
| **返回** | 删除最后一位数字。只剩一位时，离开查找 |

设置也响应其他名称。例如，“promiscuous”可找到**数字监听**，“TOT”可找到**发射超时**。

## 临时更改与永久更改

操作时所做的更改（功率、静噪、亚音、时隙、色码、模式、通话目标）都是临时的。它们持续到你切换信道或在主屏幕按 **返回**。
主屏幕会标记已更改的字段。要把更改保留在信道中，在主屏幕或快速设置中长按 **OK**。电台显示“已保存到信道”。

在 VFO 中，电台自动保留更改，因此长按会显示“VFO 设置自动保存”。静噪是整台电台共用的一项设置，因此在 VFO 中设置的静噪
也会成为每个信道的默认静噪，与在信道上长按 **OK** 保存的效果相同。如果另一次写入正在进行，电台显示“保存忙：请重试”。
稍等片刻，再长按 **OK**。

在主屏幕上每按一次 **返回**，按以下顺序清除一项：

1. 正在输入的频率。
2. 横幅。
3. 扫描。
4. 回复窗口。
5. 数字监听。
6. 所有临时更改一起清除（“已撤销更改”）。

## 按键锁

在主屏幕上长按 **\*** 锁定按键。屏幕显示“按键已锁：长按 * 解锁”，状态行显示“L”。按键锁定时，**PTT** 和**监听**仍然可用。
其他按键和信道旋钮会显示解锁提示。再次长按 **\*** 解锁。音量旋钮仍然可用，除非关闭了**设置 > 按键锁 > 锁定时旋钮**。
在菜单中长按 **\*** 不会锁定按键，因此缓慢的按键不会在任务中途锁住按键。

**设置 > 按键锁 > 自动锁键**会在一段时间无按键后自动锁定按键。只有侧键（没有键盘、没有 **返回** 键）的电台从不自动锁定，
因为没有办法解锁。

## 提示与横幅

短消息称为提示（toast），显示在提示行中约两秒。提示显示操作的结果，或某项功能不可用的原因。较长的提示会占用提示行上方的
第二行，且不会被截断。

横幅公告事件（消息、呼叫提示、电台检查结果），显示八秒。关于消息或呼叫提示的横幅显示时，**#** 打开相关内容。
在主屏幕按 **返回** 可隐藏它。
