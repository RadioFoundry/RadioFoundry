# DMR

DMR 语音需要编解码器（[安装](02-installing.md)）和电台频率中的 DMR ID。哪些电台有 DMR，见[功能矩阵](../feature-matrix.md)。

## 术语

| 术语 | 含义 |
|---|---|
| 通话组（TG） | 一个 DMR 组号码，可带名称 |
| 联系人 | 一个人：DMR ID、名称、呼号 |
| 通话目标 | **PTT** 当前发往的对象：通话组、个人或全呼 |
| 收听列表 | 信道收听的通话组（电台频率中的接收组列表） |
| 最近 | 听到的台站和发起的呼叫，最新的在前 |
| 数字监听 | 播放此频率上的所有呼叫：任意通话组、时隙或色码（混杂模式） |
| 时隙（TS） | DMR 信道的两个时隙之一 |
| 色码（CC） | DMR 信道使用的 0 到 15 的数字，作用类似 FM 上的亚音 |

## 你会听到谁

满足以下任一条件时，电台播放组呼：

- 其通话组是通话目标的通话组，或该呼叫是全呼。
- 其通话组在信道的收听列表中。
- 在回复窗口期间，它是回复目标（[回复](#replying)）。
- 数字监听已打开。

电台播放发给你的 DMR ID 的个呼。该时隙上的其他所有呼叫显示为“其他通话组：不播放”，呼叫持续期间电台把信道视为忙。

即使在收听任意色码时，发射仍使用信道的色码。

除非数字监听已打开，中继信道只收听自己的时隙。电台从中途加入的呼叫，显示的是该呼叫的呼叫方和通话组，
而不会显示另一个时隙上的呼叫或之前的呼叫的信息。

## 你与谁通话

**PTT** 按以下顺序确定发送对象：

1. 列表中焦点所在的通话组或个人，一次（单次）。
2. 回复窗口运行期间的回复目标。
3. 暂时选择的通话目标。
4. 电台频率中信道的通话目标。没有通话目标的信道与其接收组列表中的第一个通话组通话，连列表都没有时才使用通话组 9。

主屏幕在“PTT→”之后显示结果。

## 选择通话目标

在 DMR 信道上长按 **#** 打开通话目标选择器：其中有信道的默认目标、回复目标、接收组列表中的通话组、最近的通话组，
以及用于手动拨 ID 或通话组的“输入号码……”。**通话目标**侧键打开同一个选择器。

通话目标有三种持续方式。

| 持续方式 | 方法 | 持续时间 |
|---|---|---|
| 单次 | 在任何列表（联系人、最近、查找、选择器、操作）中把焦点移到通话组或个人上，按 **PTT** | 本次呼叫及其回复窗口 |
| 暂时 | 把焦点移到其上并按 **OK**。电台显示“正在呼叫 ...” | 直到你切换信道或在主屏幕按 **返回** |
| 永久 | 把焦点移到其上并长按 **OK**。电台显示“现默认： ...” | 写入信道 |

永久通话目标必须是电台频率中的联系人。输入的号码只能暂时使用。电台显示“非已存联系人：仅临时”。

### 通话目标选择器

在 DMR 信道上按**通话目标**（或 **\***、**8**）。选择器按顺序列出：

| 行 | 标记 |
|---|---|
| 信道的通话目标 | 默认 |
| 最近听到的呼叫：其通话组，个呼时为呼叫方 | 回复 |
| 信道收听列表中的通话组 | 监听 |
| 最近中的通话组 | 最近 |
| 输入号码…… | |
| 选择联系人…… | |

有回复行时，焦点从回复行开始。

| 按键 | 对焦点行的作用 |
|---|---|
| **PTT** | 与其通话一次 |
| **OK** | 暂时使用它 |
| 长按 **OK** | 设为信道的默认目标 |
| **#** | 打开其操作 |

“输入号码……”打开查找。输入通话组或 ID，把焦点移到所需的行上，按 **PTT** 或 **OK**。

“选择联系人……”打开[联系人](#contacts)，即电台频率中的所有联系人和通话组。转动旋钮，或按 **上** 和 **下** 浏览，
或输入名称的字母或 ID 的数字查找。按键作用与选择器相同。在顶部按 **上** 转到最后一个联系人。

<img src="../ux/screens/160x120i5/talk_target_picker.png" width="200" alt="通话目标选择器">

在 FM 信道上，**通话目标**显示“通话目标：仅 DMR 信道”。

### 输入通话组或 ID

在主屏幕上输入号码。查找列出“通话 TG 3100”和“个呼 3100”（该 ID 是联系人时带名称）。把焦点移到其中一个上，
按 **PTT** 呼叫一次，或按 **OK** 暂时使用。

在集群信道上，查找还在最后列出“电话 5551234”：在其上按 **PTT**，会通过系统的电话网关呼叫该号码（系统没有电话网关时会拒绝）。
来自电话网络的呼叫显示呼叫方的号码；系统没有发送号码时显示“电话”。

## 回复

电台播放一次呼叫后，回复窗口打开。在窗口期间，**PTT** 应答该呼叫。组呼在同一通话组上应答，个呼则回复给呼叫方。
你自己发起呼叫后，**PTT** 再次发往同一目标。主屏幕显示“回复→”、目标和倒计时。

<img src="../ux/screens/160x120i5/home_reply.png" width="200" alt="回复窗口期间的主屏幕">

窗口持续时间由**设置 > 通话与收听 > 回复窗口**决定（0 到 30 秒）。0 关闭窗口。该设置保持初始值时，使用电台频率中的挂起时间。
电台频率中没有挂起时间时，窗口持续 10 秒。在主屏幕按 **返回** 结束窗口（“回复已结束”）。

## 稍后回呼

在主屏幕上，**#** 打开当前或最近来电方的操作。数字选择操作。

<img src="../ux/screens/160x120i5/caller_actions.png" width="200" alt="最近来电方的操作">

| # | 操作 | 作用 |
|---|---|---|
| 1 | 通话对象 | 暂时与听到对方时所在的通话组通话。个呼之后则与对方通话。在此行按 **PTT** 通话一次 |
| 2 | 个呼 | 暂时与对方个呼。在此行按 **PTT** 呼叫对方一次 |
| 3 | 消息 | 打开消息编写器（[消息](10-messages-and-signaling.md)） |
| 4 | 电台检查 | 检查对方的电台是否开机且在范围内 |
| 5 | 呼叫提示 | 寻呼对方的电台 |
| 6 | 位置 | 始终为灰色 |
| 7 | 存为联系人 | 用对方的 ID 和名称打开新建联系人（[联系人](#contacts)）。对方已是联系人时显示“已在联系人中” |
| 8 | 语音状态 | 始终为灰色 |
| 9 | 保存到信道 | 仅在信道有临时更改时显示 |
| 最后一项 | 请求数据 | 仅在集群信道上显示。向对方的电台请求其短数据；应答以消息形式到达。没有应答时显示“请求：无数据” |

对于通话组，操作为通话对象、设为默认信道和消息；通话组不是联系人时还有 4 存为联系人。

还没有听到任何人时，**#** 显示“暂无通话记录”。

## 最近

**OK**、**3**。最近列出最后 12 个听到的台站和发起的呼叫，最新的在前。你发起的呼叫以箭头开头。发给你的呼叫高亮显示，
个呼显示“you”或“priv”。最近保存在内存中，重启后为空。

<img src="../ux/screens/160x120i5/recent.png" width="200" alt="最近">

**PTT** 与焦点条目通话（听到该台站时所在的通话组）。**OK** 暂时使用它。长按 **OK** 设为永久。**#** 打开其操作。

## 联系人

**OK**、**1** 列出电台频率中的全部联系人和通话组。输入名称的字母或 ID 的数字可筛选。联系人用于你要呼叫的通话组和人；
其他人由 [ID 数据库](04-programming.md#dmr-id-database-and-contacts-from-radioidnet)命名。**OK** 暂时与焦点条目通话。
长按 **OK** 设为信道的默认目标。**PTT** 与其通话一次。**#** 打开其操作。

<img src="../ux/screens/160x120i5/contacts.png" width="200" alt="联系人">
<img src="../ux/screens/160x120i5/contact_actions.png" width="200" alt="联系人的操作">

### 新建联系人

在电台上可以从联系人、号码或呼叫新建联系人：

- 在联系人（**OK**、**1**）中，第一行是**新建联系人**。按 **OK**，然后输入名称和 ID，并选择类型。
- 在主屏幕上输入 ID 或通话组。没有联系人使用该号码时，查找的最后一行是“新建联系人 3100”。按 **OK**。
  不超过 6 位数字时初始为通话组，7 位及以上为个人。
- 在呼叫方或通话组的操作（**#**）中，选择**存为联系人**。

<img src="../ux/screens/160x120i5/contact_edit.png" width="200" alt="新建联系人">

| 行 | **OK** 的作用 |
|---|---|
| 名称 | 用键盘输入名称（[文字输入](07-channels-zones-vfo.md#text-entry)） |
| ID | 输入 ID。**返回** 删除一位，**OK** 保留 |
| 类型 | 通话组或个呼 |
| 时隙 | 信道的、TS 1 或 TS 2 |
| 保存 | 保存联系人。在任意行上长按 **OK** 也会保存 |

电台拒绝已存在的联系人（“已是联系人： ...”）。电台不能编辑或删除已保存的联系人：请使用 qdmr。从 CPS 写入电台频率会替换你在电台上
新建的联系人，因此请先把电台频率读入 CPS。

## 个呼

- 从联系人发起：**OK**、**1**，找到该人，**#**、**2**（个呼），然后按 **PTT**。或把焦点移到该人上并按 **PTT**。
- 按 ID 发起：在主屏幕上输入 ID，把焦点移到“个呼 ...”上并按 **PTT**。
- 要应答个呼，在回复窗口期间按 **PTT**。

通话期间，顶行显示“个呼”，屏幕显示联系人的名称（[发射](06-home-screen.md#transmitting)）。

在 DMR 信道上，**\*** 打开以下磁贴：

| **6** | 加密 | 打开或关闭加密。在 VFO 中此磁贴为发射频率（[异频](07-channels-zones-vfo.md#split-repeater-offset)） |
| **7** | 双守 | 打开或关闭双守候 |

| **9** | 亮度 | 打开亮度编辑器 |

要更改色码，按 **\***、**3**。按 **上** 或 **下**，或输入色码（0 到 15）。按 **OK** 应用。新的色码在编辑器关闭时生效。

<img src="../ux/screens/160x120i5/quick_cc_editor.png" width="200" alt="编辑色码">

（[VFO](07-channels-zones-vfo.md#dmr-in-the-vfo)）。

## 唤醒中继台

空闲的中继台在转发你的呼叫之前可能需要唤醒。在中继信道上（发射和接收频率不同），你按 **PTT** 时电台发送唤醒信号，
然后等待中继台应答。短按即可：松开 **PTT** 后电台会继续尝试，直到达到通常的尝试次数。

| 你听到的 | 含义 |
|---|---|
| 通话许可音（如已打开） | 中继台已应答。如果你仍按住 **PTT**，呼叫开始。如果没有，不再发送任何内容，你可以再按 **PTT** |
| 低沉的错误音 | 没有中继台应答。检查色码和你的距离 |

## 通话许可音

通话许可音告诉你电台已占用信道，你可以讲话。在**设置 > 声音 > 通话许可音**中为所有信道关闭它，或用信道的**通话许可音**字段为单个信道关闭。

大多数电台在你的语音开始发射时播放两声短促的提示音。提示音会被发射出去的电台，改为在发射前播放一声短促的提示音
（[该电台的说明](23-radios.md)）：

| 屏幕 | 发生了什么 |
|---|---|
| 唤醒中继 | 在中继信道上，电台唤醒中继台（如上所述） |
| 已准许 | 信道归你使用：提示音在电台仍处于接收时播放 |
| 通话中 | 电台正在发射。开始讲话 |

等待提示音的时间不到半秒。在此期间松开 **PTT** 会取消呼叫。

你听到的呼叫结束时的提示音是呼叫结束音。信道的**通话许可音**字段也会关闭它。

## 数字监听

数字监听播放此频率上的所有呼叫：任意通话组、任一时隙、任意色码。它一次播放一个呼叫，即它最先听到的那个，直到该呼叫结束。
通话屏幕显示该呼叫的时隙，与信道不同时还显示其色码（“TS2 CC7”）。要与他们通话，把信道设为该时隙和色码
（**\***、**2** 和 **\***、**3**）。

- 在 DMR 信道上按**监听**（短按；松开时生效）。电台显示“数字监听开”，标签显示“数听”。再按一次关闭。
  在 FM 信道上，同一个键在按住期间打开静噪。
- 或按 **\***、**5**。

数字监听一直打开，直到你关闭它、切换信道或模式，或在主屏幕按 **返回**。在数字监听打开时启动的[扫描](12-scan.md)会在每个信道上保持它打开。
数字监听打开时，回复窗口让你可以用 **PTT** 应答听到的任何呼叫。**PTT** 始终在信道的时隙和色码上发送，
因此在其他时隙或色码上听到的呼叫收不到回复。数字监听播放另一个时隙上的呼叫时，信道视为忙。

## 加密

RadioFoundry 有两种基础加密：Motorola 基础加密（密钥 1 到 255）和 Anytone 16 位基础加密。基础加密是对语音的固定扰码。
它能挡住随意收听的人，但不是加密算法意义上的加密。

- 只有在拥有匹配的密钥时，电台才播放加密呼叫。没有密钥时，呼叫显示为“已加密：不播放”。
- 使用更强加密的呼叫（它们发送 PI 头）从不播放。
- **\***、**6** 为你的呼叫打开加密（“暂时开启加密”）。主屏幕显示“加密”。在主屏幕按 **返回** 再次关闭。

要在电台上设置密钥，打开**设置 > 加密**（**OK**、**7**、**4**）。

1. 在**密钥类型**上按 **OK**，直到显示 Motorola 或 Anytone。
2. 在**密钥**上按 **OK**。用数字键以十进制输入密钥（Motorola 为 1 到 255，Anytone 为 0 到 65535）。再按 **OK**。

电台在重启后保留密钥。把类型设回“关”会删除密钥并关闭加密。电台频率不保存加密密钥。开发者也可以用调试工具通过 USB 载入密钥：

```
tools/rfoundry_debug.py radio privacy moto 5          # Motorola basic privacy, key 5
tools/rfoundry_debug.py radio privacy anytone 4660    # Anytone basic privacy, key 4660
tools/rfoundry_debug.py radio privacy off
```

没有密钥时，加密磁贴显示“无密钥：在设置 > 加密 中设置”。密钥以未加保护的形式保存在电台的闪存中。

## 通话中的位置

有些 DMR 电台会在语音呼叫中发送自己的位置（ETSI GPS Info）。呼叫方发送位置时，接收屏幕显示对方的距离和方向，例如“12.3 km NE”。
电台不知道你自己的位置时，显示呼叫方的坐标。最近会随呼叫保存距离。

电台知道自己的位置（见[位置](17-settings.md#position)），且以下任一项要求发送时，你自己的位置会加入你的呼叫：

| 位置 | 适用于 |
|---|---|
| **设置 > 位置 > DMR 通话带位置**（默认关闭） | 所有 DMR 呼叫 |
| 电台频率：信道在其时隙上的通话者别名设置为 APRS 或 Both | 该信道上的呼叫 |

从电脑为电台编程时，应使用电台频率中的设置：电台上无需任何设置。这在没有 APRS 的电台上也可用；在没有 GPS 的电台上，设置固定位置后也可用。
每隔一个超帧携带一次位置，与你的通话者别名轮流发送。

## 通话者别名

接收屏幕会显示其他电台发送的通话者别名，随到随显示。**设置 > 通话与收听 > 显示主叫别名**可关闭此功能。
电台频率中信道的通话者别名设置要求时，电台把电台频率中的呼号（8 个字符）作为你自己的别名发送。

## 漫游

在不同站点转发相同通话组的 DMR 中继台系统上，电台所在的中继台信号变弱时，电台可以自行移到更好的中继台。漫游按区域打开。

1. 把同一系统的中继信道放入一个区域，每个信道设为同一个联系人。
2. 选择其中一个信道，然后打开**工具 > 漫游**，打开**在本区域漫游**。

空闲时，电台监视其所在中继台的信号。信号持续低于门限时，电台收听区域中的其他站点，并移到它能听到的最强的站点。
在通话、扫描或热点使用期间、你发射时，或通话结束后可能有回复的 3 秒内，它从不移动。主屏幕在中继标签旁显示 `Roam`，
当前站点信号弱时显示琥珀色的 `Roam?`。搜索期间，状态条显示 `ROAM`。提示显示“已移至”和新信道的名称。

| 行 | 作用 |
|---|---|
| 在本区域漫游 | 为当前区域打开或关闭漫游 |
| 立即漫游 | 立即搜索各站点 |
| 锁定本站点 | 停留在当前中继台，直到你解锁（主屏幕显示 `Lock`） |
| 站点测量 | 中继台信标的排列方式：已同步（默认）、按站点或关 |
| 信标间隔 | 中继台发送信标的频率：60 秒（默认）、2、5 或 10 分钟、10 到 30 秒，或无 |
| 信标长度 | 每个信标持续的时间：1 到 10 秒（默认 4 秒） |
| 唤醒探测 | 开：电台短暂地让安静的中继台发射以测量它。这会发射。默认关闭 |

许多中继台系统让每个中继台在空闲时短暂发射。这称为“信标”，例如每分钟 4 秒，所有中继台同时发送。电台学习其中继台的信标何时到来。
每个信标期间，它跳到其他几个站点，每个停留不到一秒，测量后返回。屏幕始终显示你的中继台。按键、**PTT** 或所访问站点上的呼叫
会让它立即返回。电台不在时，在你的中继台上开始的呼叫最多会晚约 3 秒加入，因此有通信后电台会暂停测量一段时间。
你的中继台信号变弱时，电台在下一个信标时检查它测量到的最佳站点并移到那里，通常在一分钟之内。把**信标间隔**和**信标长度**
设为与系统一致（向其运营方询问）。如果每个中继台按自己的时间表发送信标，选择**按站点**。如果它们不发送信标，选择**无**：
电台随后依靠它听到的呼叫。在电台得知时间表之前，屏幕显示“信标：学习中”，之后显示“信标：测量中”。

站点是区域中与你所选信道联系人相同的中继信道（发射和接收频率不同）。区域中任一信道设置了电台频率的漫游标志时，只有带标志的信道才是站点。
至少需要两个站点。你自己切换信道或区域时，新信道成为主信道。

门限（默认 -105 dBm）、滞后（6 dB）以及可选的定期搜索其他站点，通过调试链路设置（[dmr-roaming](../spec/dmr-roaming.md) 第 5.1 节）。
调试链路还可设置运行 MMDVM SFR 的热点为漫游电台发送的空闲信标（`rpt_beacon`，默认关闭）。

礼貌接入会等最近的活动过期后再发射。即使不再有突发到达，安静的信道也会重新变为可用。

## 集群系统

DMR Tier III 集群系统为每次呼叫分配一个信道。电台停留在系统的控制信道上，在那里注册，然后转到系统授权的信道。
系统设置每次呼叫的频率、时隙和色码，因此集群信道没有自己的这些设置。

哪些电台运行集群，见[功能矩阵](../feature-matrix.md)。

### 设置集群系统

在电台频率编辑器中（[编程](04-programming.md#digital-modes-and-systems)）：

1. 在**系统**标签页添加一个类型为 DMR Tier III Trunking 的系统。输入其网络模型、NET、类别和色码，以及它的信道，
   并在控制信道上勾选**控制**。系统的运营方掌握这些值。
2. 新建一个信道，把其**模式**设为 DMR Tier III Trunking 并选择该系统。它的联系人是你的通话对象；它的接收组列表是你收听的通话组。
3. 把该信道与其他信道一起放入一个区域。

| 设置 | 作用 |
|---|---|
| 发射 | 从不（仅收听）：电台跟随系统及其呼叫，但从不在那里注册或发射。在运营方启用你的电台的 ID 之前使用此项 |
| 需要密钥 | 用于对电台进行认证的系统。在表单的**密钥**一节中输入密钥；没有密钥时该信道无法使用 |
| 本系统上的电台 ID | 你在该系统上的 ID，当它与电台的 DMR ID 不同时 |
| 备用信道 | 找不到系统时使用的常规信道（见下文）。每个信道可以指定自己的备用信道，或不指定 |

在编辑器中设为仅接收的信道在系统上也保持仅接收：电台收听，并拒绝 PTT。

### 使用集群系统

选择该信道。主屏幕显示系统的名称以及电台在那里的状态，取代时隙和色码：

| 主屏幕显示 | 含义 |
|---|---|
| 搜索中 | 正在寻找系统的控制信道 |
| 正在注册 | 已找到；正在向系统注册 |
| 就绪 | 在控制信道上。按住 **PTT** 呼叫 |
| 通话中 | 在系统授权的信道上，正在通话 |
| 已拒绝 | 系统拒绝了注册。PTT 被拒绝 |
| 备用信道 | 没有找到控制信道：在备用信道上 |
| 系统未设置 | 信道的系统缺失、没有控制信道或缺少密钥。该信道为仅接收 |

按住 **PTT**：电台向系统请求信道，系统授权后开始通话。系统拒绝或没有应答时，PTT 被拒绝。通话目标是信道的联系人，
或像在任何 DMR 信道上一样由你选择的目标（[选择通话目标](#choosing-a-talk-target)）。

在区域和信道列表中，集群信道在显示频率的位置显示其系统的名称。系统未设置的信道显示为灰色，切换信道时会跳过它。扫描会跳过集群信道。

### 后备

电台在保持时间内（除非系统另行设置，否则为 30 秒）没有找到控制信道时，会转到备用信道，并像在任何信道上一样在那里工作。
该信道安静时，电台每 10 秒再次寻找系统。找到后，电台返回，发出提示音，并显示“已回到”和系统的名称。

### 遥晕与遥毙

系统可以停用它不再信任的电台。除非你为该系统打开（**接受遥晕**、**接受遥毙**），否则两者都关闭。

| | 发生了什么 | 解除方式 |
|---|---|---|
| 遥晕 | 电台留在系统上，但不能在那里呼叫或跟随呼叫。关机后仍保持 | 系统的唤醒，或恢复出厂设置 |
| 遥毙 | 所有 DMR 停止，包括每个信道和热点。FM 仍可用。只接受来自电台持有其密钥的系统的遥毙 | 只能恢复出厂设置 |

在没有密钥的系统上，任何发出遥晕的发射机发来的遥晕都会被接受：在那里请保持**接受遥晕**关闭。
