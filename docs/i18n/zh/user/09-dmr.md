# DMR

[电台参考](23-radios.md)说明哪些电台的 DMR 已验证。DMR 语音需要编解码器（[安装](02-installing.md)）以及电台频率中的 DMR ID。

## 术语

| 术语 | 含义 |
|---|---|
| 通话组（TG） | DMR 组号，可带名称 |
| 联系人 | 一个人：DMR ID、名称、呼号 |
| 通话目标 | **PTT** 当前的去向：通话组、个人或全呼 |
| 收听列表 | 信道收听的通话组（电台频率中的接收组列表） |
| 最近 | 听到的台站和发起的呼叫，最新的在前 |
| 数字监听 | 播放此时隙上的所有通话组（混杂模式） |
| 时隙（TS） | DMR 信道的两个时隙之一 |
| 色码（CC） | DMR 信道使用的 0 到 15 的数字，类似 FM 上的亚音 |

## 你会听到谁

当以下任一条件成立时，电台会播放组呼：

- 其通话组是通话目标的通话组，或该呼叫为全呼；
- 其通话组在信道的收听列表中；
- 在回复窗口期间它是回复目标（[见下文](#replying)）；
- 数字监听已开启。

电台会播放发往你的 DMR ID 的私密呼叫。时隙上的其他所有呼叫都会显示为“其他通话组：不播放”，并在其持续期间把信道视为忙。

## 你会与谁通话

**PTT** 依次发送到：

1. 列表中处于焦点的通话组或个人，仅一次（一次性）。
2. 回复窗口运行期间的回复目标。
3. 临时选择的通话目标。
4. 电台频率中该信道的通话目标。没有通话目标的信道会与其接收组列表中的第一个通话组通话，连列表也没有时使用通话组 9。

主屏幕在“PTT→”之后显示结果。

## 选择通话目标

在 DMR 信道上长按 **#** 打开通话目标选择器：信道默认、回复目标、接收组列表中的通话组、最近的通话组，以及“输入号码……”以手动拨号 ID 或通话组。**通话目标**侧键打开同一个选择器。

通话目标有三种存活期。

| 存活期 | 方式 | 持续时间 |
|---|---|---|
| 一次 | 在任意列表（联系人、最近、查找、选择器、操作）中聚焦通话组或个人并按 **PTT** | 本次呼叫及其回复窗口 |
| 临时 | 聚焦并按 **OK**。电台显示“正在通话……” | 直到你切换信道或在主屏幕按 **返回** |
| 永久 | 聚焦并长按 **OK**。电台显示“……现为默认” | 写入信道 |

永久通话目标必须是电台频率中的联系人。输入的号码仅临时使用。电台显示“非已存联系人：仅临时”。

### 通话目标选择器

在 DMR 信道上按**通话目标**（或 **\***、**8**）。选择器按顺序列出：

| 行 | 标记 |
|---|---|
| 信道的通话目标 | 默认 |
| 最后听到的呼叫：其通话组，私密呼叫时则为呼叫者 | 回复 |
| 信道收听列表中的通话组 | 收听 |
| 来自“最近”的通话组 | 最近 |
| 输入号码…… | |
| 选择联系人…… | |

有回复行时，焦点从该行开始。

| 按键 | 对焦点行的作用 |
|---|---|
| **PTT** | 与其通话一次 |
| **OK** | 临时使用它 |
| 长按 **OK** | 设为该信道的默认 |
| **#** | 打开其操作 |

“输入号码……”打开查找。输入通话组或 ID，聚焦所需行并按 **PTT** 或 **OK**。

“选择联系人……”打开[联系人](#contacts)，即电台频率中的所有联系人和通话组。转动旋钮，或按 **上** 和 **下** 浏览，或输入名称字母、ID 数字来查找。按键属于选择器。在顶部按 **上** 会跳到最后一个联系人。

<img src="../ux/screens/160x120i5/talk_target_picker.png" width="200" alt="通话目标选择器">

在 FM 信道上，**通话目标**显示“通话目标：仅 DMR 信道”。

### 输入通话组或 ID

在主屏幕输入数字。查找会列出“通话到 TG 3100”和“私密呼叫 3100”（该 ID 是联系人时带名称）。聚焦一项，按 **PTT** 通话一次，或按 **OK** 临时使用。

## 回复

电台播放某个呼叫后，回复窗口打开。窗口期间 **PTT** 应答该呼叫。组呼在同一通话组上应答，私密呼叫则回复呼叫者。你自己呼叫之后，**PTT** 会再次发往同一目标。主屏幕显示“回复→”、目标和倒计时。

<img src="../ux/screens/160x120i5/home_reply.png" width="200" alt="回复窗口期间的主屏幕">

窗口持续多久由**设置 > 通话与收听 > 回复窗口**决定（0 到 30 秒）。0 表示关闭。该设置保持起始值时，适用电台频率中的挂机时间。电台频率中没有挂机时间时，窗口持续 10 秒。在主屏幕按 **返回** 结束窗口（“回复已结束”）。

## 稍后回拨

在主屏幕按 **#** 打开当前或最近呼叫者的操作。数字键选择操作。

<img src="../ux/screens/160x120i5/caller_actions.png" width="200" alt="最近呼叫者的操作">

| # | 操作 | 作用 |
|---|---|---|
| 1 | 通话对象 | 临时在他们被听到的通话组上通话。私密呼叫之后则与他们通话。在此行按 **PTT** 通话一次 |
| 2 | 私密呼叫 | 临时私密呼叫他们。在此行按 **PTT** 呼叫一次 |
| 3 | 消息 | 打开消息编辑（[消息](10-messages-and-signaling.md)） |
| 4 | 电台检查 | 检查他们的电台是否开机且在范围内 |
| 5 | 呼叫提示 | 寻呼他们的电台 |
| 6 | 位置 | 尚未构建 |
| 7 | 存为联系人 | 用其 ID 和名称打开新建联系人（[联系人](#contacts)）。已是联系人时显示“已在联系人中” |
| 8 | 语音状态 | 尚未构建 |
| 9 | 保存到信道 | 仅在信道有临时更改时显示 |

对通话组而言，操作是“通话对象”“设为默认信道”和“消息”，不是联系人时还有“4 存为联系人”。

尚未听到任何呼叫时，**#** 显示“暂无通话记录”。

## 最近

**OK**、**3**。“最近”列出最后听到的 12 个台站和发起的呼叫，最新的在前。你发起的呼叫以箭头开头。发给你的呼叫会高亮，私密呼叫显示“你”或“私密”。最近保存在内存中，重启后为空。

<img src="../ux/screens/160x120i5/recent.png" width="200" alt="最近">

**PTT** 与焦点条目通话（台站被听到时所在的通话组）。**OK** 临时使用它。长按 **OK** 使其永久。**#** 打开其操作。

## 联系人

**OK**、**1** 列出电台频率中的所有联系人和通话组。输入名称字母或 ID 数字可筛选。联系人用于你要呼叫的通话组和人；[ID 数据库](04-programming.md#dmr-id-database-and-contacts-from-radioidnet)为其他所有人命名。**OK** 临时与焦点条目通话。长按 **OK** 使其成为信道默认。**PTT** 与其通话一次。**#** 打开其操作。

<img src="../ux/screens/160x120i5/contacts.png" width="200" alt="联系人">
<img src="../ux/screens/160x120i5/contact_actions.png" width="200" alt="联系人的操作">

### 新建联系人

可在电台上从联系人、号码或呼叫创建联系人：

- 在联系人（**OK**、**1**）中，第一行是**新建联系人**。按 **OK**，然后输入名称和 ID 并选择类型。
- 在主屏幕输入 ID 或通话组。没有联系人使用该号码时，查找的最后一行是“创建联系人 3100”。按 **OK**。最多 6 位数字作为通话组，7 位及以上作为个人。
- 在呼叫者或通话组的操作（**#**）中选择**存为联系人**。

<img src="../ux/screens/160x120i5/contact_edit.png" width="200" alt="新建联系人">

| 行 | **OK** 的作用 |
|---|---|
| 名称 | 用键盘输入名称（[文本输入](07-channels-zones-vfo.md#text-entry)） |
| ID | 输入 ID。**返回** 收回一位数字，**OK** 保留 |
| 类型 | 通话组或私密 |
| 时隙 | 信道、TS 1 或 TS 2 |
| 保存 | 保存。在任意行长按 **OK** 也会保存 |

电台会拒绝已存在的联系人（“已是联系人：……”）。编辑或删除已存储的联系人尚未构建：请使用 qdmr。从 CPS 写入电台频率会替换你在电台上创建的联系人，因此请先把电台频率读入 CPS。

## 私密呼叫

- 从联系人：**OK**、**1**，找到那个人，**#**、**2**（私密呼叫），然后 **PTT**。或聚焦该人并按 **PTT**。
- 按 ID：在主屏幕输入 ID，聚焦“私密呼叫……”并按 **PTT**。
- 要应答私密呼叫，请在回复窗口期间按 **PTT**。

通话时顶行显示“私密”，屏幕显示联系人名称（[发射](06-home-screen.md#transmitting)）。

## 时隙与色码

在 DMR 信道上，**\*** 打开这些磁贴：

| 按键 | 磁贴 | 作用 |
|---|---|---|
| **1** | 功率 | 在电台的最低档、默认档和最高档之间步进（[功率级别](16-battery-and-power.md#transmit-power)） |
| **2** | 时隙 | 临时在时隙 1 和 2 之间切换 |
| **3** | 颜色 | 打开色码编辑器 |
| **4** | 模式 | 显示 DMR。按下可临时在同一频率上以 FM 收听和通话 |
| **5** | 数字监听 | 开或关数字监听 |
| **6** | 加密 | 开或关加密。在 VFO 中此磁贴为发射频率（[分离](07-channels-zones-vfo.md#split-repeater-offset)） |
| **7** | 双守候 | 开或关双守候 |
| **8** | 通话对象 | 打开通话目标选择器 |
| **9** | 亮度 | 打开亮度编辑器 |
| **0** | | 打开设置 |

要更改色码，按 **\***、**3**。按 **上** 或 **下**，或输入代码（0 到 15）。按 **OK** 应用。新色码在编辑器关闭时生效。

<img src="../ux/screens/160x120i5/quick_cc_editor.png" width="200" alt="编辑色码">

时隙和色码是临时的。发射时无法更改。长按 **OK** 可将它们保存到信道。在 VFO 中它们是 VFO 自身的设置并会保留（[VFO](07-channels-zones-vfo.md#dmr-in-the-vfo)）。

## 唤醒中继台

空闲的中继台在承载你的呼叫前可能需要唤醒。在中继信道（收发频率不同）上，按下 **PTT** 时电台会发送唤醒，然后等待中继台应答。短按即可：松开 **PTT** 后电台会继续尝试，直到通常的尝试次数。

| 听到 | 含义 |
|---|---|
| 允许发射提示音（若已开启） | 中继台已应答。若你仍按住 **PTT**，呼叫开始；若已松开，则不再发送，你可以再按 **PTT** |
| 低声错误音 | 中继台无应答。请检查色码和距离 |

## 数字监听

数字监听会播放此频率、时隙和色码上的所有通话组。

- 在 DMR 信道上按**监听**（短按，松开时生效）。电台显示“数字监听开”，标签显示“数字监听”。再按一次关闭。在 FM 信道上，同一键在按住期间打开静噪。
- 或 **\***、**5**。

数字监听会一直保持，直到你关闭它、切换信道或模式，或在主屏幕按 **返回**。开启期间，回复窗口允许你用 **PTT** 应答听到的任何呼叫。

## 加密

RadioFoundry 支持两种基础加密：Motorola 基础加密（密钥 1 到 255）和 Anytone 16 位基础加密。基础加密是对语音的固定置乱。它能挡住随意收听者，但不是加密。该置乱尚未与其他电台对照验证（[电台参考](23-radios.md)）。

- 电台只有持有匹配密钥时才会播放加密呼叫。没有密钥时，呼叫显示为“已加密：不播放”。
- 使用更强加密的呼叫（发送 PI 头）绝不会播放。
- **\***、**6** 为你的呼叫打开加密（“临时开启加密”）。主屏幕显示“加密”。在主屏幕按 **返回** 会再次关闭。

要在电台上设置密钥，请打开**设置 > 加密**（**OK**、**7**、**4**）。

1. 在**密钥类型**上按 **OK**，直到显示 Motorola 或 Anytone。
2. 在**密钥**上按 **OK**。用数字键以十进制输入密钥（Motorola 1 到 255，Anytone 0 到 65535）。再按 **OK**。

电台会在重启后保留密钥。把类型设回“关”会移除密钥并关闭加密。电台频率目前无法保存加密密钥。开发者也可用调试工具通过 USB 载入密钥：

```
tools/rfoundry_debug.py radio privacy moto 5          # Motorola 基础加密，密钥 5
tools/rfoundry_debug.py radio privacy anytone 4660    # Anytone 基础加密，密钥 4660
tools/rfoundry_debug.py radio privacy off
```

没有密钥时，加密磁贴显示“无加密密钥：在设置 > 加密 中设置”。密钥在电台闪存中未加保护地保存。

## 呼叫中的位置

有些 DMR 电台会在语音呼叫中发送位置（ETSI GPS Info）。呼叫者发送时，接收屏幕会显示距离和方向，例如“12.3 km 东北”。电台不知道你自己的位置时，会显示呼叫者的坐标。“最近”会随呼叫保留距离。

当**工具 > APRS > DMR 呼叫中的位置**开启（默认关闭）且电台知道自己的位置时（见 [APRS](13-aprs.md#position)），你的位置会随呼叫发送。每隔一个超帧携带它，与你的通话者别名轮流。

## 通话者别名

接收屏幕会显示其他电台发来的通话者别名，随到随显。**设置 > 通话与收听 > 显示主叫别名**可关闭。当电台频率中信道的通话者别名设置要求时，电台会把电台频率中的呼号（8 个字符）作为自己的别名发送。

## 漫游

在由多个站点承载相同通话组的 DMR 中继系统中，当前中继台信号变弱时，电台可以自行转到更好的中继台。漫游按区域开启。

1. 把同一系统的中继信道放入一个区域，每个都设为相同联系人。
2. 选择其中一个，然后打开**工具 > 漫游**并开启**在此区域漫游**。

空闲时，电台监视所在中继台的信号。信号持续低于阈值时，电台会收听区域内其他站点，并转到能听到的最强站点。在呼叫、扫描或热点使用期间，在你发射时，以及呼叫结束后 3 秒内（可能收到回复）绝不切换。主屏幕在中继台标签旁显示 `Roam`，当前站点较弱时显示琥珀色 `Roam?`。搜索期间状态条显示 `ROAM`。toast 会显示“已移动到”和新信道名称。

| 行 | 作用 |
|---|---|
| 在此区域漫游 | 为当前区域开启或关闭漫游 |
| 立即漫游 | 立即搜索各站点 |
| 锁定到此站点 | 停留在当前中继台，直到你解锁（主屏幕显示 `Lock`） |
| 站点测量 | 中继台信标的对齐方式：同步（默认）、按站点、关闭 |
| 信标间隔 | 中继台发送信标的频率：60 秒（默认）、2/5/10 分钟、10 到 30 秒，或无 |
| 信标长度 | 每个信标持续多久：1 到 10 秒（默认 4 秒） |
| 唤醒探测 | 开：电台会短暂发射以测量安静的中继台。这会发射。默认关闭 |

许多中继系统让每个中继台在空闲时短暂发射。这就是“信标”，例如每分钟 4 秒，所有站点同一时刻。电台会学习中继台信标的到来时间。每个信标期间，它会跳到其他几个站点，每个不到一秒，测量后返回。屏幕仍显示你的中继台。按键、**PTT** 或被测站点上的呼叫会让它立即返回。电台离开期间在你中继台上开始的呼叫最多会晚约 3 秒加入，因此有通话后电台会暂停测量一段时间。你的中继台变弱时，电台会在下一个信标时检查测得的最佳站点并转过去，通常在一分钟内。把**信标间隔**和**信标长度**设为与系统一致（可询问其运营者）。若各中继台按自己的时间表发送信标，选择**按站点**。若它们不发送信标，选择**无**：电台将依赖听到的呼叫。在电台了解时间表之前，屏幕显示“信标：学习中”，之后显示“信标：测量中”。

站点是区域中与你所选信道具有相同联系人的中继信道（收发频率不同）。当区域中任何信道设置了电台频率的漫游标志时，只有带标志的信道才是站点。至少需要两个站点。你自己切换信道或区域会使新信道成为当前站点。

阈值（默认 -105 dBm）、迟滞（6 dB）以及可选的定期搜索其他站点目前通过调试链路设置（[dmr-roaming](../spec/dmr-roaming.md) 第 5.1 节）。调试链路还设置运行 MMDVM SFR 的热点可为漫游电台发送的空闲信标（`rpt_beacon`，默认关闭）。
