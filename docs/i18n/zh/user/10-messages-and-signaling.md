# 消息、呼叫提示与电台检查

DMR 文本消息、呼叫提示和电台检查在 DMR 信道上可用。在带 AFSK 发射通路的构建上，电台还通过 FM 发送 APRS 文本消息。
哪些电台有哪种通路，见[功能矩阵](../feature-matrix.md)。它们都不需要编解码器。DMR 发送需要一个你可以在其上发射的 DMR 信道，
以及你的 DMR ID。APRS 发送需要**设置 > 我的电台**中的有效呼号、一个业余 APRS 频率，以及支持 AFSK 发射的电路板。

## 接收消息

消息到达时，电台显示一个横幅，其中包含发送方和开头几个字，持续 8 秒。要打开消息，在横幅显示时按 **#**。
除非关闭了**设置 > 声音 > 消息提示音**，电台会随横幅播放一段短促的三音提示音。在有振动马达的电台上，除非关闭了
**设置 > 声音 > 振动**，它还会振动两次。呼叫提示或发给你的个呼振动一次长振，紧急振动四次。

<img src="../ux/screens/160x120i5/banner_message.png" width="200" alt="消息横幅">

横幅之后，状态行显示“M”和未读消息数，hub 在“消息”旁显示“1 新”。

## 阅读消息

1. 按 **OK**、**2**（消息）。最新的消息在最前。未读消息高亮显示。
2. 把焦点移到一条消息上并按 **OK**。电台显示发送方、到达了多久以及文字内容，并把消息标为已读。
3. 文字下方有：

   | 行 | 作用 |
   |---|---|
   | 显示全文 | 在单独的页面上显示全文。**上** 和 **下** 滚动，**返回** 返回。仅在文字太长、屏幕以“…”结尾时出现 |
   | 回复“OK” | 向发送方发送“OK” |
   | 回复“马上到” | 向发送方发送“马上到” |
   | 呼叫 | 把发送方暂时设为通话目标 |
   | 删除 | 删除消息。无法撤销 |

在 DMR 消息上按 **#** 打开其发送方的操作。在打开的 DMR 消息中按 **PTT** 呼叫发送方。APRS 消息的发送方是呼号，
因此“呼叫”操作对它不可用。在 APRS 消息上按 **#** 打开一个发往该呼号的编写器。

电台把 DMR 和 APRS 消息保存在内存中。电台关机时它们会丢失。

## 发送消息

1. 打开对某人或某通话组的操作。在主屏幕上按 **#** 打开最近来电方的操作，或在联系人上按 **#**。
2. 按 **3**（消息）。
3. 选择一条预设消息（“OK”、“马上到”、“打给我”或“暂时不能通话”），或选择**编写……**输入你自己的文字。按 **OK** 发送。
   预设消息以电台的语言发送（设置 > 显示 > 语言）。

<img src="../ux/screens/160x120i5/compose.png" width="200" alt="消息编写器">

电台显示“正在发送至 ...”并回到主屏幕。发给个人的消息会请求确认。没有收到确认时，电台会用每种格式再试。结果以横幅显示：

| 横幅 | 含义 |
|---|---|
| “已送达 ...” | 对方的电台确认了消息 |
| “无应答： ...”，并显示“未送达：请重发” | 没有收到确认。消息不会被保留以便重试。请从操作中再次发送 |
| “已发送至 ...” | 发往通话组的消息已发出。通话组消息没有确认 |

关闭确认 IP 数据时（`tools/rfoundry_debug.py data ip-settings auto off`），发给个人的 ETSI 消息也只发送一次，并显示“已发送至”。

在**编写……**中，用数字键输入字母，用 **#** 在 ABC、123 和 abc 之间切换，用 **返回** 删除。一条 DMR 消息最多 143 个字符。
你发送的消息不保存在电台中。

### 通过 APRS 发送

1. 在构建包含 APRS 且已设置呼号时，打开**消息 > 新 APRS 消息**。也可以打开**收到的台站**，选择一个台站并选择**消息**，
   以填入其呼号。
2. 选择**发往呼号**，输入收件人的呼号，可带 SSID（例如 `K1ABC-9`）。按 **OK** 保留。
3. 根据需要选择**请求确认**和**APRS 位置**，然后选择一条预设消息或**编写……**，按 **OK** 发送。两项选择只适用于这条消息。
   APRS 消息最多 67 个字符。预设消息使用电台的语言；带重音的字母发送时会去掉重音，以保持 AX.25 文字可打印。
   电台把 APRS 消息排入所配置 FM 频率的发送队列。“正在发送至 ...”表示已排队，而不是已送达。

**请求确认**初始为开。等待回复期间电台会重试。对于不需要送达确认的单次消息，关闭它。**APRS 位置**初始为关。
打开时，电台把当前的 GPS、电脑提供的或固定位置以十进制坐标加入消息文字。没有可用位置，或文字加坐标超过 67 个字符时，
电台拒绝发送。位置是消息正文的一部分，而不是单独的位置信标。

APRS 的目的地是呼号，而不是 DMR ID。新发出的消息会替换仍在等待确认的消息。呼号或文字无效，或 APRS 射频通路不可用时，
发送会被拒绝。**工具 > APRS** 显示所配置的频率和任何阻止发送的原因。收到的 APRS 消息显示在消息中；回复通过 APRS 发送。

## 消息格式

**设置 > 连接 > 消息格式**选择新 DMR 消息的编码。无论如何设置，电台都能读取全部三种 DMR 格式。对 DMR 收件箱消息的回复使用 DMR。

| 格式 | 用途 |
|---|---|
| ETSI（默认） | 标准 DMR 文本消息（ETSI IP 文本）。设为“DMR 标准”文本的电台和调度软件可以读取。发给个人的消息有送达确认 |
| ETSI 简码 | 只显示 ETSI 短数据消息的电台。有送达确认 |
| Motorola | 设为 Motorola 文本消息（TMS）的商用 DMR 电台和调度软件。有送达确认。不含 Motorola TMS 支持的构建中没有此项 |

如果你的电台在 ETSI 成为默认值之前已设置过，且其数据设置已保存，它会继续发送 Motorola 消息，直到你更改设置。

## 呼叫提示

呼叫提示寻呼另一台电台。即使那台电台的用户没有收听你的通话组，它也会在那里响铃。

1. 打开对该人的操作（主屏幕上的 **#**，或联系人上的 **#**）。
2. 按 **5**（呼叫提示）。电台显示“呼叫提示至 ...”并回到主屏幕。
3. 电台最多尝试 3 次。结果以横幅显示：“... 已回应提示”或“无应答： ...”。

有人向你发送呼叫提示时，电台显示“呼叫提示来自 ...”和“PTT 可回复”。在横幅显示时按 **#** 打开对呼叫方的操作。
除非关闭了**设置 > 连接 > 应答呼叫提示**，你的电台会确认该提示。

## 电台检查

电台检查请求另一台电台应答，而无需其用户做任何操作。它显示那台电台是否开机且在范围内。

1. 打开对该人的操作。
2. 按 **4**（电台检查）。电台显示“正在检查 ...”。
3. 电台最多尝试 3 次。结果以横幅显示。“... 已接听（0.8 s）”给出往返时间。“...: no answer”会伴随
   “Off, out of range or elsewhere”。

<img src="../ux/screens/160x120i5/banner_radio_check.png" width="200" alt="电台检查结果">

**设置 > 连接 > 应答电台检查**打开时（默认），你的电台应答他人的电台检查。应答是电台在你没有按 PTT 的情况下进行的短暂发射；
如果你不希望这样，关闭此设置。

## 注册（ARS）与位置（LRRP）

ARS 在开机和切换信道后向在线状态服务器注册电台。在你设置服务器 ID 之前它是关闭的：**设置 > 连接 > 数据服务 > ARS 服务器**。
输入服务器的 DMR ID 并按 **OK**；0 关闭 ARS。屏幕显示注册状态：正在注册、已注册、已拒绝或无应答。该 ID 保存在电台频率中，
因此[电台频率编辑器](04-programming.md)也可以设置它。

LRRP 应答调度员的位置请求。没有 GPS 的电台（[电台参考](23-radios.md)）应答“无定位”。**设置 > 位置 > 应答 GPS 请求**可关闭这些应答。
