# 简介

RadioFoundry 是面向低价 DMR 电台的自由固件，采用 MIT 许可。它替换电台的原厂固件。一个与机型无关的核心提供 DMR 协议栈、用户界面、电台频率和主机工具；每款电台在其下增加薄薄的一层板级支持。

本手册描述 RadioFoundry 在每款电台上的行为。各机型之间的差异（按键、功率级别、电池、电源开关、显示屏、缺少的硬件和测试状态）见[电台参考](23-radios.md)。截图是 160 x 120 的；其他电台显示相同的屏幕，只是按其显示屏布局。

## 电台与项目状态

[电台参考](23-radios.md)列出受支持的电台、每款电台已检查的项目，以及正在开发中的机型。[功能矩阵](../feature-matrix.md)按电台列出各项功能。只有发行版中列出的电台可以直接使用。

RadioFoundry 是早期软件。每项功能属于以下三类之一。

| 类别 | 含义 |
|---|---|
| 已在电台上验证 | 在电台上测试过；涉及射频时通过空中在 SDR 台架上测试。[电台参考](23-radios.md)说明每款电台验证了什么 |
| 已构建、主机测试 | 在主机测试中针对模拟芯片工作，或只在电台上部分检查过 |
| 尚未构建 | 在菜单中变暗显示，选择时给出提示：语音提示、手动输入文本消息、快速拨号、在电台上编辑或删除已保存的联系人 |

有些功能并非每款电台都有：要么硬件缺少相应部件，要么该电台的板级代码尚未编写。[电台参考](23-radios.md)按电台列出。

## RadioFoundry 提供什么

- DMR 语音：组呼与私密呼叫、通话者别名、基础加密、呼叫中的位置（ETSI GPS Info）。
- DMR 数据：文本消息、呼叫提示、电台检查、ARS 注册、LRRP 位置应答。
- DMR 紧急：告警、带热麦的紧急呼叫、他人发起紧急时的提醒。
- 按区域进行 DMR 中继台漫游。
- FM：CTCSS 与 DCS 亚音、静噪、监听、12.5 与 25 kHz 带宽、VOX、双音多频。
- VFO：手动调谐频率，支持 FM 或 DMR。具备硬件的电台还可接收航空波段 AM 和调频广播。
- 区域扫描或 VFO 频段扫描，以及两个信道的双守候。
- APRS：FM 上的位置、状态和消息，DMR 上的位置，以及 KISS TNC。
- 热点：电台作为 MMDVM 调制解调器，供 MMDVMHost 和 Pi-Star 类主机使用，并支持单频中继模式（MMDVM SFR）。
- USB 网络模式：电台作为 USB 网卡，并通过 DMR 承载 IP。在这条链路上提供状态页、rig 控制、KISS over TCP、TFTP 电台频率访问、SNMP 和 mDNS，也可作为调度软件的控制站。
- 在浏览器中用电台频率编辑器或 qdmr 编程，以及由 RadioID.net 构建的 DMR ID 数据库。

## AMBE 编解码器

DMR 语音需要 DVSI 专有的 AMBE+2 声码器。RadioFoundry 从不附带它。每款电台运行其原厂固件中的编解码器。安装器保留电台中已有的编解码器，或从电脑上的原厂固件文件取出并写入电台（[安装](02-installing.md)）。没有编解码器时，电台可用于 FM、显示 DMR 呼叫并处理 DMR 数据，但不播放也不发送 DMR 语音。

## 本手册的约定

按键以其承担的功能命名。每款电台把这些功能分配到自己的按键上。[按键角色](23-radios.md#key-roles)给出了每款电台的对照表。

名称包括 **OK**、**返回**、**上**、**下**、**\***、**#**、**0** 到 **9**、**监听**、**通话目标**、**功率级别**、**上一区域**、**下一区域** 和 **PTT**。电台上没有其中某个键时，可通过菜单完成该功能。

“长按”指按住按键至少 0.6 秒，这是可在[设置](17-settings.md)中调整的长按时间。“按”指短按。菜单路径用 `>` 表示：**设置 > 显示 > 亮度** 表示打开设置，再打开显示，再打开亮度。

屏幕文字按实际显示引用，例如“已保存到信道”。
