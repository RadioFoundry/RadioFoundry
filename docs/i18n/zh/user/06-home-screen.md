# 主屏幕

主屏幕一眼回答四个问题：你在哪里、**PTT** 会做什么、正在发生什么，以及电台是否正常。

<img src="../ux/screens/160x120i5/home_dmr.png" width="200" alt="DMR 信道上的主屏幕">
<img src="../ux/screens/160x120i5/home_fm.png" width="200" alt="FM 信道上的主屏幕">

## 各区域，从上到下

| 区域 | 显示内容 |
|---|---|
| 状态行 | 左侧：状态（IDLE、RX、TX，电台拒绝发射时为 NO TX；只要静噪打开就为 RX，监听也包括在内）、模式（DMR 或 FM）、扫描或监听开启时的 SCAN 或 MON，以及 USB 作为网卡时的 IP，电脑连接后其后跟一个向上箭头和一个向下箭头。右侧：按键锁定时为“L”，未读消息为“M”加数字，信号条、电池图标和电池百分比。在彩色屏上，该行用高亮色填充，文字为黑色（**设置 > 显示 > 状态栏填充**） |
| 位置 | 区域名称和信道在区域中的位置（“3/16”）。在 VFO 中：“VFO” |
| 信道 | 信道编号和名称，在能放下的范围内尽量大。在 VFO 中：频率 |
| 通话目标 | 一个箭头，以及 **PTT** 发往哪里。DMR：通话组或个人，例如“TG 91 World”；名称太长放不下时，先截断（“TG 201 Main O…”）再省略。FM：发射频率。回复窗口期间：填充框中的返回箭头和倒计时。要让通话组名称在前（“World TG 91”），打开**设置 > 显示 > 通话组名称在前**，或给侧键分配 **TG 名称/号码**（**设置 > 按键**） |
| 标签 | DMR：时隙、色码、中继信道上的“Rpt”，以及功率（电台听到中继台时显示信号条）。FM：亚音、带宽、功率和静噪级别 |
| 活动 | 空闲：最后听到的台站及多久以前，或“暂无通话记录”。电台发射前需要的设置排在最前，用警告色显示（“请设置: Board revision”或“请重启电台”），提示行说明在哪里设置。接收或发射时：见下文各节 |
| 提示行 | 最近的几个按键当前的作用 |

暂时更改过的字段（临时更改）在主屏幕上用高亮色绘制，提示行显示“返回 撤销  长按 OK 保存”。

<img src="../ux/screens/160x120i5/home_temporary.png" width="200" alt="临时更改功率后的主屏幕">

电池百分比在低电量警告级别（默认 15%）及以下时变为警告色。

## 提示行消息

提示行随情况变化。**返回** 键的作用始终位于该行右端、按键上方。最常见的提示：

| 提示 | 含义 |
|---|---|
| OK 菜单  \* 快捷  # Joe | 常规提示。# 后面的名字是最近来电方。**#** 打开对其的操作 |
| 返回 撤销  长按 OK 保存 | 信道有临时更改 |
| # 来电方  返回 结束回复 | 回复窗口正在运行。**PTT** 应答最近的呼叫 |
| 返回：信道通话组 | 正在使用暂时选择的通话目标（行较窄时显示“返回 默认目标”） |
| 数字监听  返回 关闭 | 数字监听已打开 |
| # 跳过  返回 停止扫描 | 扫描正在运行 |
| 无编解码器：语音关闭 | 在 DMR 信道上，且电台没有编解码器 |
| 0-9 频率  \* 快捷  上下 | 在 VFO 中 |
| 按键已锁：长按 \* 解锁 | 按键已锁定（行较窄时显示“已锁：长按 \* 解锁”） |

## 接收

DMR 呼叫期间，主屏幕显示呼叫方：

- 名称，来自你的联系人，否则来自电台频率中的 DMR ID 数据库。
- DMR ID 和时隙。
- 陆续到达的通话者别名，除非关闭了**设置 > 通话与收听 > 显示主叫别名**。
- 通话组，或“发给你的个呼”。
- 信号强度。在 DMR 中，这是最近 120 ms 的峰值，因此空闲时隙不会显示为下降。

<img src="../ux/screens/160x120i5/rx_group.png" width="200" alt="接收组呼">
<img src="../ux/screens/160x120i5/rx_private.png" width="200" alt="接收个呼">

电台听到但不播放的呼叫会显示原因：“其他通话组：不播放”（你不收听的通话组）、“已加密：不播放”或“无编解码器：语音关闭”。
要收听其他通话组上的呼叫，长按**监听**。

在 FM 上，静噪打开时活动区域显示“接收中”，监听时显示“静噪打开”。

## 发射

按住 **PTT** 期间，屏幕显示“通话中”、目标、时隙和色码（DMR）、发射时长和发射超时。DMR 把时间显示为“0:07 / 3:00”，
FM 显示为“剩余 2:53 / 3:00”。

在 DMR 上，顶行显示呼叫类型：组呼为“TG 3100”，个呼为“个呼 9991234”。个呼显示联系人的名称，有空间时还显示其 ID。
名称太长时，该行保留名称，省略 ID。

<img src="../ux/screens/160x120i5/tx.png" width="200" alt="发射组呼">
<img src="../ux/screens/160x120i5/tx_private.png" width="200" alt="发射个呼">

在 DMR 上，屏幕可能先显示“等待”（电台等待空闲时隙）或“唤醒中继”（电台正在唤醒中继台）。电台唤醒中继台期间，
每发送一次唤醒信号，红色 LED 闪烁一次；开始发射后常亮。

在 DMR 上，电台也会在没有 **PTT** 时发射：注册（ARS）、文本消息、位置、呼叫提示及其应答，以及来自 USB 或串口上电脑的分组数据。
此时状态行显示 TX，红色 LED 点亮，主屏幕显示“发送中”。电台接收数据时，状态行显示 RX。

电台拒绝发射时，状态行显示 NO TX，LED 按红、绿、红、绿、红、绿闪烁一遍，并伴有拒绝提示音。在繁忙的信道上没有提示音，
你正在收听的呼叫继续播放。屏幕说明原因，提示行说明该怎么做：

| 消息 | 原因 | 该怎么做 |
|---|---|---|
| 本信道仅接收 | 信道设为仅接收 | 换一个信道 |
| 超出…… | 频率超出电台的发射频段 | 换一个信道，或在 VFO 中调到某个频段内 |
| 已达发射超时 | 你的通话时间超过了发射超时 | 松开 **PTT** 再按 |
| 未设发射频率 | 信道没有发射频率 | 在电台频率中修正该信道 |
| 无编解码器：语音关闭 | DMR 语音缺少编解码器 | “用 rfoundry 添加编解码器”（[无编解码器](20-troubleshooting.md#no-codec-no-codec-voice-off)） |
| 信道忙 | 该时隙上有其他人在通话 | 等待呼叫结束 |
| 中继台无应答 | 中继台没有被唤醒 | “检查色码和距离” |
| 热点模式：PTT 关闭 | 电台正作为热点 | 按 **OK** 退出热点模式 |
| 电台频率中无 DMR ID | 电台频率没有 DMR ID | 在电台频率中设置你的 ID |
| DMR 调制解调器未运行 | DMR 芯片没有启动 | 重启电台。见[故障排查](20-troubleshooting.md) |
| 请设置: Board revision（或其他硬件选项） | 电台无法检测该选项，在得知之前不会发射 | **设置 > 高级 > 硬件**（[电台参考](23-radios.md)中你的电台一节说明该选什么） |
| 请重启电台 | 你更改了一个硬件选项，它从下次启动起生效 | 关闭电台再打开 |
| 电台拒绝发射 | 电台的发射机拒绝了这次发射 | “松开 PTT 再试”。如果反复出现，重启电台 |
| 调制解调器拒绝发送 | DMR 芯片拒绝了呼叫，或接受后 1.5 秒内什么都没发送 | “松开 PTT 再试”。如果反复出现，重启电台 |

低电量和严重低电量级别也会限制发射。见[电池与供电](16-battery-and-power.md)。

## 大字体

**设置 > 显示 > 大字体**只显示状态行、信道名称和通话目标，每项在能放下的范围内尽量大。关机后电台保留此设置，
也保留**设置 > 显示 > 提示行**。
