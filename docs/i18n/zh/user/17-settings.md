# 设置

用 **OK**、**7**，或 **\***、**0** 打开设置。设置按用途分组。数字键直接打开某个分组。查找也能按名称找到每项设置：在主屏幕输入其开头字母。

<img src="../ux/screens/160x120i5/settings.png" width="200" alt="设置">
<img src="../ux/screens/160x120i5/settings_display.png" width="200" alt="设置，显示">

## 更改设置

每行显示当前值。

- 开关和列表设置用 **OK** 更改：每按一次切换到下一个值。
- 数字设置在按 **OK** 时打开编辑器。用 **上** 和 **下**（或信道旋钮）更改数值，或用数字键输入，按 **OK** 保留，按 **返回** 保持不变。输入超出范围或位于步进之间的值不会被接受：电台显示“未更改”及范围。
- 设置一更改就生效并保存，没有单独的保存步骤。

<img src="../ux/screens/160x120i5/settings_editor.png" width="200" alt="编辑数字设置">

有些设置在其背后的功能存在之前就在菜单中，或对本电台不适用。它们会变暗。在变暗的行上按 **OK** 会说明原因。各表的状态列表示：

| 状态 | 含义 |
|---|---|
| 有效 | 立即生效，并在关机后保留 |
| 有效，不保留 | 立即生效，关机后恢复默认 |
| 变暗 | 尚未构建，或本电台没有。按 **OK** 说明原因 |

| 麦克风降噪 | 开、关 | 开 | 减少你在 DMR 上发送内容中的稳定背景噪声（风扇、发动机、风），词间也有效。若想保留的稳定声音被切掉，请关闭。语音编解码器不支持的电台此项变暗 | 需要空中验证（DMR） |
| 默认数字监听 | 开、关 | 关 | 每次选择 DMR 信道时开启数字监听（DMR：所有通话组，混杂模式）。在主屏幕按 **返回** 会关闭它，直到下一个信道 | 有效 |

| 双守候延时 | 0.5、1、1.5、2、3、5 秒 | 1 秒 | 呼叫结束后双守候在信道上停留多久以等待回复。期间它查看另一信道并在那里显示**忙**（[双守候](12-scan.md#the-wait-after-a-call)） | 有效 |
| SFR 接收 | 中继、首个副本、双路接收 | 中继 | 实验性。单频中继用户播放什么（[独立 SFR](14-hotspot.md#standalone-sfr)）。中继：只播放中继台的副本。首个副本：通话者或中继台的副本，以先到者为准。双路接收：两份都用，每个损坏的语音帧取自另一份。不含该功能的构建缺少双路接收 | 有效（中继）。首个副本和双路接收取决于电台：有些一次只能听到一份副本（[电台参考](23-radios.md)） |
| SFR CW 标识 | 关、5、10、15、30 分钟 | 关 | 实验性。单频中继信道多久以摩尔斯码发送一次呼号（[独立 SFR](14-hotspot.md#standalone-sfr)）。呼号是电台名的第一个词（空格、`-` 或 `/` 之前），且必须像呼号：4 到 7 个字母和数字，两者至少各一个。否则不发送。中继台承载过通话并安静 2 秒后，标识以 FM 在信道上发出，每个间隔最多一次。不含该功能的构建缺少此项 | 有效 |

## 恢复出厂设置

**设置 > 高级 > 恢复出厂设置**会询问“将所有设置恢复为出厂默认？信道保留。此操作无法撤销。”焦点从“不，保留设置”开始。聚焦“是，重置”并按 **OK**。

<img src="../ux/screens/160x120i5/factory_reset.png" width="200" alt="恢复出厂设置确认">

重置会把每项设置恢复默认（亮度、电台设置、加密密钥、信道位置），擦除 RadioFoundry 自己的数据区，并重启电台。电台频率和校准保留。

## 崩溃日志

固件崩溃时，电台会保留一份简短记录，说明发生位置和原因，然后重启。停止响应约 3 秒的电台也算崩溃：记录显示“挂起”。**设置 > 高级 > 崩溃日志**显示该记录：发生了什么、连续崩溃次数、电台运行了多久以及固件构建。没有记录时显示“无崩溃记录。”关机可能会丢失记录：请先查看再关机。

<img src="../ux/screens/160x120i5/crash_log.png" width="200" alt="设置 > 高级 > 崩溃日志">

| 项目 | 作用 |
|---|---|
| 发送报告 | 在当前信道上经 DMR 把记录发送到“发送至”联系人。空中需要几秒；随后显示“崩溃报告已发送”或“崩溃报告未发送” |
| 发送至 | 报告发往的联系人，私密或组呼：从联系人中选择（输入以查找） |
| 崩溃后 | 关：重启时什么都不做。询问：电台询问是否发送报告。自动：不询问直接发送。默认关 |
| 清除 | 忘记该记录 |

询问和自动需要“发送至”联系人，以及电台可发射的 DMR 信道。报告最多约 150 字节，不含音频、消息或位置：只有崩溃记录和固件构建。空中没有任何内容确认它已到达。

## 没有菜单的设置

电台中有一些设置尚未出现在菜单中：

- 忙信道锁定和 roger beep；
- 扫描的恢复模式和时序；
- VOX 灵敏度；
- ARS 服务器和紧急设置；
- IP 数据设置（头压缩、确认数据）和 SNMP 团体名；
- 漫游阈值、迟滞和定期搜索；
- SFR 空闲信标。

开发者通过调试链路更改它们（`tools/rfoundry_debug.py radio set ...`、`data settings ...`、`data ip-settings ...`、`snmp ...`）。电台会保留它们。漫游测量和信标设置在**工具 > 漫游**中（[DMR](09-dmr.md#roaming)）。

没有设置菜单的构建（`CONFIG_UI_SETTINGS=n`）改为显示“请用 qdmr 设置”，并保留已存值。
