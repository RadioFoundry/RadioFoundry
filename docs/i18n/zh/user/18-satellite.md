# 卫星跟踪

卫星跟踪使用从电脑安装的 TLE 记录。电台不会下载轨道数据。可选的 `CONFIG_SATELLITE_TLE` 功能需要板级构建具备专用卫星存储和调试链路支持。

## 安装轨道数据

用调试链路 USB 连接电台。在电脑上浏览受支持的星表：

```sh
python tools/satellite_tle.py catalog --source amsat
```

也可在浏览器中打开 RadioFoundry 网站的 **工具 > 卫星 TLE 更新**。加载 AMSAT 每日公告，或浏览选择 TLE 文件，再按名称选择最多 10 颗 FM 卫星。非 FM 目标不显示。如果列表中有 ISS、SO-50 和 AO-91，它们会默认选中。搜索不会清除已勾选的选择。每次推送或下载数据包前，页面都会刷新 AMSAT 公告；若选择了文件，则按原样使用。推送会替换已勾选卫星的现有 TLE，并校验其历元。该页面可以通过 USB/串口直接推送，也可以生成 JSON 数据包供电脑工具使用。直接推送需要受支持的浏览器和安全上下文（HTTPS 或 localhost）。安装或更新后，如果已安装构建支持卫星功能，网页安装器会提供此页面。

只安装你选择的目录编号。可重复使用 `--id`，或用逗号分隔编号：

```sh
python tools/satellite_tle.py sync --source amsat --id 25544,43017
```

要离线准备数据，先把所选编号抓取到数据包，校验后再在电台连接时安装：

```sh
python tools/satellite_tle.py fetch --id 25544 --output satellites.json
python tools/satellite_tle.py validate satellites.json
python tools/satellite_tle.py install satellites.json
```

工具在传输所选数据前会检查两行 TLE、它们的身份和校验和，以及轨道根数的时效。网站会替换卫星 TLE 清单和所选频率配置。命令行的 `sync` 和 `install` 也会用所选记录替换整个 TLE 清单；仅含轨道数据的数据包不会改变频率配置。两种方式都不会创建、修改或删除电台频率中的区域或信道。发射前请查看 [AMSAT 实时 FM 卫星列表](https://www.amsat.org/live-fm-satellites/)，确认卫星当前工作状态。内置频率快照依据该页面 2026 年 10 月 31 日的更新。SO-50 需要发射 2 秒 74.4 Hz CTCSS 来启动定时器；之后切回其正常的 67.0 Hz 上行亚音。使用 `read` 查看已安装的编号和历元：

```sh
python tools/satellite_tle.py read
```

频率配置与轨道根数是分开的。TLE 每日公告不含频率；页面使用 AMSAT 实时 FM 表中的已知条目，目前覆盖表中所有 FM 卫星。非 FM 目标不列入。配置列表最多 10 项。网站推送会用所选卫星替换电台的卫星 TLE 表和频率表，因此未选择的卫星会从跟踪列表中消失。电台频率不变。电脑工具还可以直接读取或修改内置配置编号列表：

```sh
python tools/satellite_tle.py profiles
python tools/satellite_tle.py profiles --id 25544,27607,43017
```

电脑工具执行替换需要协议 v4 或更高版本。schema v3 频率数据包需要协议 v5。协议 v5 最多支持 4 个所选频率配置；协议 v6 支持完整 10 个。仅更改配置编号需要协议 v3 或更高版本。

## 在电台上输入 TLE

按 **OK**、**6**（工具），再选择 **卫星**。选择一次过境以打开该卫星的详情，然后按 **#**。输入完整的 69 字符第一行 TLE，按 **OK**；再输入完整的第二行，再次按 **OK**。电台保留现有目录编号和名称。它会校验两行，并作为一个事务提交替换；错误或不完整的两行不会替换已安装数据。此操作会从头编辑两行，输入时请保留原始 TLE。

## 跟踪卫星

按 **OK**、**6**（工具），再选择 **卫星**。电台使用所选位置源的坐标和高度，并使用最新的 GPS 或电脑 NMEA 提供 UTC，预测已安装 TLE 的过境。因此，只要接收机提供当前日期和时间，已保存的固定位置就能在 GPS 首次定位期间提供观测者位置。电脑提供的定位和 UTC 不会在重启后保留：请重新发送包含高度和日期/时间的 NMEA。

列表按距 AOS 的时间排序，并显示每次过境的最大仰角。预测完成后，第一次过境会高亮显示。用 **上** / **下** 选择过境；按 **OK** 打开详情并开始跟踪。所选卫星会在关机后保留。

固件镜像中不含 TLE。通过网站的“卫星 TLE 更新”页面或 `tools/satellite_tle.py sync`，把所选记录加载到电台的闪存存储。存储为空时，卫星页面显示 **无TLE：请从网站加载**。有当前 UTC 时，过境列表会显示最早安装的 TLE 的时效。即使卫星一起刷新，各 TLE 的时效也可能不同。达到 14 天时，每次更新清单都会提示一次，要求刷新这组数据以提高预测精度。

过境和多普勒数值使用近似开普勒轨道模型，而不是 SGP4。它们可能与精密星历不同，TLE 越旧差异越明显，因此请保持已安装轨道根数为最新。

跟踪时的标称接收/发射频率和可选发射 CTCSS 亚音来自持久化的目录编号配置，而不是所选 VFO 或电台频率信道。没有已保存配置的卫星无法开始跟踪。跟踪期间，电台使用 FM 和 12.5 kHz 带宽；停止跟踪后恢复原有设置。TLE 提供方只提供轨道根数，不提供通信频率。电脑同步不会改动电台频率；编辑现有信道也不会改变跟踪使用的运行时配置。

只有当接收和发射频率都落在电台支持的频段内时，电台才会接受频率配置。TLE 工具会检查所连接电台的频段，并在单频段电台无法使用所选配置时报告。若只需安装 TLE 用于过境预测、不安装频率配置，请使用 `tools/satellite_tle.py sync`。

屏幕显示接收和发射多普勒频偏、当前经多普勒校正的接收和发射频率，以及下一次过境的 AOS 和 LOS 倒计时。北向上的圆形天空图显示从地平线到天顶的预测路径，并在卫星可见时标出当前位置。128x64 显示屏的详情页面用 AOS 和 LOS 倒计时代替天空图。升起时间在左，落下时间在右。卫星在轨可见时，升起倒计时显示 **当前**。

正在发射时，发射行显示当前使用的频率；跟踪会在后台继续计算最新目标，并在发射结束后立即应用。

正在跟踪 SO-50 时，在其详情页面长按 **OK**，发送 2 秒 74.4 Hz CTCSS 启动信号。电台会执行正常发射检查，并使用当前经多普勒校正的上行频率。这不会改变配置中正常的 67.0 Hz 亚音；松开 PTT 时也绝不会自动发送启动信号。

电台一次只保留一次过境：即将到来的过境在 AOS 时成为当前过境，LOS 后跟踪推进到下一次过境。缺少位置、高度、有效 UTC、记录不可用或 TLE 过旧时，跟踪会话不可用，也不会应用校正。停止跟踪、信道/VFO 上下文改变、开始扫描或热点模式，或所需输入失效时，电台会恢复普通信道频率。

在已选中当前跟踪卫星时再次按 **OK**，或离开其详情页面，即可停止跟踪并恢复之前的信道或 VFO 设置；离开页面时会显示“跟踪已停止”提示。打开 TLE 编辑器或快速设置不会停止跟踪。如果正在发射，电台会在发射结束后恢复设置。开始跟踪另一颗卫星会替换当前跟踪会话。跟踪不会绕过正常的发射频段、禁发或正在发射规则。
