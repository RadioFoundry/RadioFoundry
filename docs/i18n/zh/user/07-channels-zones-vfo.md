# 信道、区域与 VFO

**信道**是一个保存的频率，带有模式（FM、DMR，或在支持它们的电台上的 P25 和 NXDN）和设置。**区域**是一个有名称的信道列表。
**VFO** 用于手动调谐任意频率。信道和区域来自电台频率（[为电台编程](04-programming.md)）。

## 切换信道

- 在主屏幕上转动信道旋钮，或按 **上** 或 **下**，逐个切换区域中的信道。
- 在主屏幕上输入信道的位置并按 **OK**。例如，**1**、**2**、**OK** 转到区域的第 12 个信道。
- 在主屏幕上输入信道名称的字母（见[查找](05-keys-and-navigation.md#find)），在该信道上按 **OK**。
- 按 **OK**、**4**（区域），把焦点移到区域上并按 **#**。区域的信道列表打开。把焦点移到一个信道上并按 **OK**。

<img src="../ux/screens/160x120i5/zone_channels.png" width="200" alt="区域的信道">

切换信道会结束临时更改、回复窗口、数字监听和扫描。

## 切换区域

- 按**下一区域**或**上一区域**（[按键角色](23-radios.md#key-roles)显示你的电台上它们是哪些键）。电台显示“区域：”和名称。
- 或按 **OK**、**4**（区域）。列表打开时焦点在当前区域上（“此处”）。把焦点移到另一个区域并按 **OK**。
  电台切换到该区域并回到主屏幕。
- 或在主屏幕上输入区域的名称。查找也会列出区域。

<img src="../ux/screens/160x120i5/zones.png" width="200" alt="区域：VFO 和各区域">

区域列表先显示 VFO，然后是每个区域及其信道数。输入字母可筛选列表。

## 新建区域

1. 按 **OK**、**4**（区域），然后选择最后一行**新建区域**。
2. 输入名称并按 **OK**。电台保存这个空区域，并在列表中把焦点移到它上面。
3. 按 **#** 打开区域，用**添加信道**添加信道。

信道自己的页面也可以把信道放入区域（**区域**行，见[编辑信道](#editing-a-channel)）。

## 编辑区域

区域的列表（**OK**、**4**，焦点移到区域上，**#**）也用于编辑区域。电台立即保存每项更改：无需保存或放弃。
在没有 **#** 键的电台上，本节中凡说 **#** 之处都改为长按 **OK**。

<img src="../ux/screens/160x120i5/zone_actions.png" width="200" alt="区域中的信道操作">

- **添加信道**（第一行）列出区域中没有的所有信道。输入字母或数字筛选，在其中一个上按 **OK**。
  它会放在你所在的信道之后；对于你没有在使用的区域，放在末尾。
- 在信道上按 **#** 打开其操作：

  | 按键 | 操作 | 作用 |
  |---|---|---|
  | 1 | 上移 | 与上方的信道交换位置。菜单保持打开，再按 **1** 可继续上移 |
  | 2 | 下移 | 与下方的信道交换位置 |
  | 3 | 复制到此处 | 在最小的空闲信道编号处打开一个副本，名称后加“ 2”。修改不同之处并长按 **OK**：副本被保存，并放在本区域中该信道之后 |
  | 4 | 编辑信道 | 打开信道的设置（[编辑信道](#editing-a-channel)） |
  | 5 | 共享信道至…… | 把信道发送给另一台电台或一个通话组（[共享区域](#sharing-a-zone)） |
  | 6 | 从区域移除 | 把它从本区域移出。该信道仍保留在信道列表和其他任何区域中 |

- **区域选项**（最后一行）：

  | 按键 | 操作 | 作用 |
  |---|---|---|
  | 1 | 重命名 | 输入新名称并按 **OK** |
  | 2 | 复制为新区域 | 新建一个含相同信道的区域，名称后加“ 2” |
  | 3 | 共享区域至…… | 把区域发送给另一台电台或一个通话组（[共享区域](#sharing-a-zone)） |
  | 4 | 删除区域 | 先询问，焦点在“否，保留”上。区域中的信道仍保留在信道列表中 |

<img src="../ux/screens/160x120i5/zone_options.png" width="200" alt="区域选项">

移动、添加和移除时，电台保持在当前信道上。移除你所在的信道时，电台移到区域中的下一个信道。一个区域中每个信道只出现一次，
超出区域容量的信道会被电台拒绝（“区域已满”）。电台频率中没有区域的电台显示一个区域“All channels”；第一次更改会把它保存为真正的区域。

删除你正在使用的区域时，电台移到列表中它之后的区域（如果它是最后一个，则移到之前的区域）。如果另一个区域包含被删除区域中的信道，
双守候继续守候该信道，否则停止。标记为漫游的区域在删除时失去该标记；其他标记仍保留在各自的区域上。

## 共享区域

你可以通过 DMR 把一个区域或一个信道发送给另一台电台或一个通话组。

**发送：**

1. 调到一个 DMR 信道。区域通过该信道发出。
2. 按 **OK**、**4**（区域）。把焦点移到区域上并按 **#**。区域的信道列表打开。
3. 发送一个信道：在该信道上按 **#**，选择 **5 共享信道至……**，或在信道的设置中选择**共享信道至……**。
   发送整个区域：选择**区域选项**（最后一行），然后选择 **3 共享区域至……**。
4. 选择一个联系人或通话组并按 **OK**。对于不是联系人的台站，输入它的 ID：联系人下方会出现“个呼 ID ...”和“TG ...”。
   电台会说明发往何处：“正在发送至 ... 经 442.375”（在中继台上为中继台的输出频率）。发送完成时，横幅显示“已发送至 ...”。

一次发送放不下的区域会只发送一部分，电台会说明发送了多少（“正在发送 40 / 60 个信道”）。扫描列表、组列表和加密密钥从不发送。

**接收：****设置 > 连接 > 接受区域共享**默认为**开**。在你同意之前，不会导入任何内容。要忽略他人发送的内容，把它设为**关**。

<img src="../ux/screens/160x120i5/zone_offer.png" width="200" alt="收到区域共享：导入、预览、拒绝">

1. 横幅显示“区域来自 ...”。它一直显示，直到你按 **#** 打开它或按 **返回** 隐藏它。该共享还会在
   **工具 > 收到的区域/信道**下保留 10 分钟。屏幕标题为**收到区域共享**；单个信道时为**收到信道共享**。
2. 共享显示区域的名称、其中的信道、发送方，以及有多少信道超出你的电台的频段。
3. 选择**预览**查看信道，**导入**添加它们，或**拒绝**。

导入的作用：

- 区域添加在你的区域之后。如果你已有同名区域，新区域名称后加“ 2”。
- 只导入你的电台能接收的信道。每个信道都是**仅接收**：确认你可以使用某个信道后，再为它打开发射。
- 你已有的通话组和联系人沿用你的名称。缺少的会被添加。
- 同一台电台再次发送同一个区域时，会更新你的副本，而不是再添加一个。它只替换上次导入中你没有改动过的信道。
  你添加到区域中的信道或改动过的信道保留，排在新信道之后。
- 单个信道会添加到你选择的区域中。

每小时最多显示 6 个共享，一次显示一个。格式见 [zone-share.md](../spec/zone-share.md)。

## 所有信道

**OK**、**5**（信道）按编号和名称列出电台频率中的所有信道，无论它们在哪些区域中。每行末尾是接收频率和通话组（DMR）或 FM。
长名称保持完整，由该行缩短其余部分：先省略“TG”，再省略频率。你所在的信道有标记。输入字母可筛选列表。

<img src="../ux/screens/160x120i5/channels.png" width="200" alt="信道：按编号列出的所有信道">

- 在信道上按 **OK** 打开其设置，可在其中更改设置（见下文）。
- 在列表中按 **#** 转到该信道：如果当前区域包含它，则在当前区域中；否则在第一个包含它的区域中。
  不在任何区域中的信道会显示“不在任何区域”。
- 第一行**用当前新建**以电台当前使用的设置新建信道（见下文）。

## 编辑信道

信道的页面列出所有设置：名称、模式、接收和发射频率、功率、仅接收；然后在 FM 上是带宽、亚音、VOX 和突发音，
在 DMR 上是色码、时隙、发射联系人、接收组列表、自身 ID、直通模式、通话许可提示音和通话者别名；然后是发射超时、扫描、
省电，以及包含它的区域。列表可以滚动。

<img src="../ux/screens/160x120i5/channel.png" width="200" alt="信道的设置">

把焦点移到一行上并按 **OK**：

| 行 | OK 的作用 |
|---|---|
| 模式 | 切换到下一个模式：FM、DMR，然后在支持的电台上为 P25 和 NXDN。继续切换会回到信道原来的模式，其设置保持原样 |
| 二选一的行（时隙、带宽、仅接收、扫描、VOX、突发音、直通模式、提示音、通话者别名、省电） | 切换到另一个选项 |
| 功率、接收亚音、发射亚音、色码、发射超时 | 打开选择器：转动旋钮（或按上 / 下）到所需的值，**OK** 保留，**返回** 取消。色码和超时也可输入数字 |
| 接收亚音、发射亚音（输入） | 输入 CTCSS 亚音时带上十分位：**8 8 5** 为 88.5，**1 3 1 8** 为 131.8。小于 60 时数字为整赫兹：**6 7** 为 67.0，**1 0 0** 为 100.0。以 **0** 开头输入 DCS 码：**0 2 3** 为 D023N。**返回** 删除最后一位。要输入反相 DCS 码，把旋钮转一格：每个码的 I 紧跟在其 N 之后（D023N、D023I、D025N） |
| 区域 | 打开所有区域，包含该信道的区域标为“在”。**OK** 把信道放入或移出某个区域，并立即保存。新信道在保存后才显示此行 |
| 接收、发射、自身 ID | 输入数字，**OK** 保留，**返回** 删除最后一位。输入时会拒绝超出电台频段的数字。新的接收频率会带动发射频率一起变化，因此中继台的偏移保持不变。如果新的接收频率在另一个频段（UHF 到 VHF），或发射频率会落到频段之外，发射频率会设为新的接收频率 |
| 名称 | 打开文字输入（见下文） |
| 发射联系人、接收组列表 | 打开联系人或组列表的列表；输入字母查找 |

<img src="../ux/screens/160x120i5/channel_power.png" width="200" alt="用旋钮选择功率级别">

更改过的行在保存之前带有标记。在页面上任意位置**长按 OK** 保存，或选择**保存**行。电台在后台写入信道，并显示“已保存信道 3”。
有未保存的更改时按 **返回**，会询问是否放弃；默认选项为“否，继续编辑”。保存任何信道都会丢弃你所在信道上的快速设置更改：
电台会从电台频率重新载入它。

以下信道电台不会保存：没有名称的信道、接收频率超出频段的信道、发射频率位于电台无法发射之处的信道（请改设为仅接收）、
位于广播波段或航空波段（在该波段以 AM 接收的电台上）的 DMR 信道，以及没有发射联系人的 DMR 信道（仅接收的除外）。
电台会说明是哪种情况。电台能接收但不能发射的 DMR 信道，设为仅接收后可以保存。

**存为新信道**把编辑后的副本保存在最小的空闲编号处，原信道保持不变。**调到本信道**调到该信道，
**共享信道至……**把它发送给另一台电台（[共享区域](#sharing-a-zone)）；请先保存或放弃你的更改。

### 文字输入

它的用法与手机键盘相同。按键 **2** 到 **9** 先输入其字母，然后是数字，然后是另一种大小写的字母：按 **2** 一次为 A，
两次为 B，四次为 2，五次为 a。在一秒内再按同一个键输入下一个字符；按另一个键或停顿则移到下一位。**1** 输入标点
（`. - / , ' & ( ) @ _ ! ?` 和 1），**0** 输入空格、0、`+`、`#` 和 `*`。标题显示当前模式。

**#** 切换模式：ABC（大写，初始模式），然后 123（每个键输入其数字），然后 abc（小写），再回到 ABC。在任何模式下长按数字键都输入该数字。
**返回** 删除最后一个字符（**\*** 也可以）。**OK** 保留名称。要不做更改就离开，按 **返回** 直到字段为空，再按一次。
名称最多 16 个字符。

在没有键盘的电台上，上 / 下更改最后一个字符，**OK** 添加一个字符，长按 **OK** 保留名称。

<img src="../ux/screens/160x120i5/channel_name.png" width="200" alt="输入信道名称">

### 用当前设置新建信道

**OK**、**5**，然后选择第一行**用当前新建**。它在最小的空闲信道编号处打开一个未保存的副本，内容取自你所在的信道
（包括所有快速设置更改）或 VFO。名称后加“ 2”（来自 VFO 时为频率）。修改不同之处，然后长按 **OK** 保存。
新信道还不在任何区域中：在区域的列表中用**添加信道**把它加入某个区域（[编辑区域](#editing-a-zone)），
或在那里用**复制到此处**一步完成复制和添加。

## 把更改保存到信道

用快速设置更改功率、静噪、亚音、带宽、时隙、色码或模式。然后在主屏幕或快速设置中长按 **OK**。电台在后台写入信道，
并显示“已保存到信道”。静噪保存为电台的默认静噪，而不是保存在信道中。

保存失败时显示“保存失败：...”，更改只暂时有效。

## VFO

VFO 是 FM VFO，在有 DMR 的电台上也可以是 DMR VFO。它像保留频率一样保留模式。你在 VFO 中更改的一切（模式、色码、时隙、通话目标）
都会保留，包括切换到信道再回来之后，以及重启之后。

1. 按 **OK**，然后按 **4**（**区域**）。VFO 是第一行。
2. 按 **OK**。主屏幕以大字显示频率，电台显示“VFO：请输入频率”。

在有 **VFO/MR** 键的电台上，改为按该键：它在信道和 VFO 之间切换。**设置 > 按键**可以给任何侧键分配同样的功能
“VFO/信道”，短按或长按均可。

<img src="../ux/screens/160x120i5/home_vfo.png" width="200" alt="VFO 中的主屏幕">

### 把信道复制到 VFO

要从某个信道开始，在该信道上按 **\***、**4**（“到 VFO”）。信道的设置成为 VFO 的设置，主屏幕显示 VFO（“已复制到 VFO”）。
在有 **VFO/MR** 键的电台上，改为长按该键。**设置 > 按键**可以给任何侧键分配“复制到 VFO”，短按或长按均可。

| 复制的内容 | 说明 |
|---|---|
| 接收和发射频率 | 中继台的偏移保持不变，直到你步进频率 |
| 模式、带宽、功率 | 信道的功率为“默认”时，VFO 的功率也保持“默认” |
| 亚音（FM） | CTCSS 或 DCS，接收和发射 |
| 色码、时隙、通话目标（DMR） | 通话目标是联系人的 ID，作为组呼或个呼。没有联系人的信道给出它此刻会发送的目标 |

- VFO 得到的是当前生效的设置，因此你在信道上所做的临时更改（带宽、功率级别、通话目标）也会被复制。
- 信道保持原样。VFO 像保留其他设置一样保留这些值，重启后也一样。
- 不复制：接收组列表、加密密钥、漫游、数据和紧急设置，以及静噪级别。VFO 对这些使用电台自己的值。
- VFO 无法容纳的信道会被拒绝，并显示简短消息，不做任何更改：在 VFO 仅支持 FM 的构建上的 DMR 信道（或反之），
  或超出电台频段的频率。
- 在 VFO 中，同一个键显示“已在 VFO 中”。

### 输入频率

在 VFO 中的主屏幕上，从百 MHz 位开始依次输入频率数字，不输入小数点。电台随输入显示你输入的内容。

| 按键 | 频率 |
|---|---|
| **4** **4** **6** **0** **0** **0** | 446.000 MHz |
| **1** **4** **6** **5** **2** | 146.520 MHz |
| **4** **3** **8** **2** **6** **2** **5** | 438.2625 MHz |
| **0** **8** **8** **1** | 88.100 MHz（低于 100 MHz 时以 **0** 开头） |

- 至少输入三位 MHz 数字，然后按 **OK**（电台有 **#** 键时也可按 **#**）调谐。
- **返回** 删除最后一位。
- 无法构成电台频段内频率的数字会被拒绝，电台显示其频段。频段因电台而异（[电台参考](23-radios.md)）。
- 最多八位数字（10 Hz）。10 秒内没有按键，输入会被丢弃。

<img src="../ux/screens/160x120i5/home_vfo_entry.png" width="200" alt="输入 VFO 频率">

### 步进

**上**、**下** 和信道旋钮按 VFO 的步进改变频率。步进为**设置 > 通话与收听 > VFO 步进**。其默认值**自动**跟随带宽：
25K（以及 AM）时为 25 kHz，12.5K 时为 12.5 kHz。在广播波段，无论 VFO 步进如何，步进总是调频广播步进。步进显示在状态条中。

### 异频（中继偏移）

在 VFO 中，**\***、**5**（DMR VFO 中为 **\***、**6**）是**发射频率**（异频）：发射相对接收，“关”或偏移量（“+600k”、“-5M”）。

<img src="../ux/screens/160x120i5/quick_vfo_split.png" width="200" alt="在发射频率中输入发射频率">

- **上** 和 **下** 立即在该频段的常用偏移之间切换。**上** 为 +，**下** 为 -，最常用的在前，到最后一个停止：

  | 频段 | 偏移 |
  |---|---|
  | 2 m（低于 200 MHz） | 600 kHz，然后 1 MHz |
  | 1.25 m（200-300 MHz） | 1.6 MHz |
  | 70 cm（高于 300 MHz） | 5 MHz，然后 7.6 MHz，然后 1.6 MHz |

  在 70 cm 上，从“关”按 **上** 为 +5M，再按为 +7.6M，再按为 +1.6M；从 +5M 按 **下** 回到“关”，再按为 -5M。
- 底行说明按键的作用（“上下 +/-  0-9 发射频率”），输入时显示到目前为止的完整发射频率（“TX 147.02___”）。
- 其他任何异频（自定义）：像输入 VFO 频率一样输入发射频率（**1 4 7 0 0** 为 147.000）并按 **OK**。**返回** 删除最后一位。
  电台能发射的任何频率都会被接受。
- 在同一频段内，新的接收频率保持偏移不变。换到另一个频段（例如 UHF 到 VHF）时，VFO 变为同频。
- 在 VFO 中，监听仍在其按键上，加密只用于信道。
- 主屏幕显示发射频率：在 FM 上位于 **PTT→** 之后；在 DMR 上位于顶行（“TX 147.120”），在没有该行的显示屏上则以偏移形式显示在功率旁边。
  发射期间，大字频率变为红色并显示发射频率（在 DMR 上，通话屏幕有一行“TX”）。

### VFO 中的 DMR

在 VFO 中，**\***、**4** 在同一频率上于 FM 和 DMR 之间切换（“VFO: DMR”）；在支持的电台上，DMR 之后还有 P25 和 NXDN
（[VFO 中的 P25](#p25-in-the-vfo)、[VFO 中的 NXDN](#nxdn-in-the-vfo)）。在 DMR 中，快速设置是 DMR 的设置：

| 按键 | 磁贴 | 在 DMR VFO 中的作用 |
|---|---|---|
| **2** | 时隙 | 切换时隙，1 或 2 |
| **3** | 色码 | 设置色码，0 到 15（初始为 1）。输入数字或用 **上** 和 **下**，然后按 **OK** |
| **8** | 通话对象 | 选择或输入通话目标，即一个通话组或一个人。**OK** 和长按 **OK** 都会为 VFO 保留它 |

<img src="../ux/screens/160x120i5/quick_vfo_dmr.png" width="200" alt="DMR VFO 中的快速设置">

- 选择你所用中继台或同频频率的色码和时隙。在你选择其他目标之前，电台以你自己的 DMR ID 与通话组 9 通话。
- VFO 没有收听列表。它播放发往其通话目标的呼叫、全呼和发给你的个呼。其他通话组显示为“其他通话组：不播放”。
  要收听该时隙上的所有内容，打开数字监听。
- 主屏幕显示频率、通话目标、时隙和色码。在这里所做的更改不显示圆点，**返回** 也不会撤销它们。
- DMR VFO 像 DMR 信道一样发送数据消息，也可以发起紧急。它不发送通话者别名。

### VFO 中的 P25

在支持 P25 的电台上（[功能矩阵](../feature-matrix.md)），P25 是 VFO 的模式之一：**\***、**4** 依次为 FM、DMR、P25，
再回到 FM（“VFO: P25”）。关机后 VFO 保留该模式。

- 它在网络接入码 293 上收听发往所有通话组的明文 P25 语音呼叫。加密呼叫保持静音。
- PTT 以你的 P25 单元 ID（电台频率中没有时用你的 DMR ID）向通话组 1 发送 P25 语音呼叫。
- 主屏幕显示“P25”、PTT 呼叫的对象（“TG 1”）和网络接入码（“NAC 293”）。通话期间，它显示谁在呼叫以及呼叫发往何处
  （“ID 3101234 > TG 7”），或呼叫不播放的原因（“已加密：不播放”、“其他通话组：不播放”）。FM 的亚音和带宽磁贴显示
  “仅 FM：这是 P25 信道”。
- 接入码、通话组和直通只能从电脑更改（`rfoundry_debug.py radio p25`），更改持续到你关闭电台。

### P25 信道

P25 信道可以来自在电脑上写入的电台频率（[编辑器中的 P25 与 NXDN](04-programming.md#p25-and-nxdn)）、另一台电台共享的区域、
VFO（在 P25 中打开**信道**，选择**用当前新建**并保存），或任何信道：在其“模式”上按 **OK** 直到显示 P25，设置 NAC 并保存。
改为 P25 的信道初始 NAC 为 293。信道保存网络接入码、通话组（某联系人有该通话组时；否则为通话组 1）和直通设置。
共享来的信道与所有共享信道一样以仅接收方式导入：在其设置中关闭仅接收。在没有 P25 的电台上，该信道显示为 P25 并保持静音。

- 主屏幕的显示与 VFO 中相同。它收听其通话组、对所有人的呼叫和发给你的 ID 的呼叫，除非电台频率设置为收听所有呼叫。
- 信道的设置把模式显示为“P25”，并只显示 P25 使用的设置。直通为“开”或“自动”（接收和发射为同一频率时为开）。
- **NAC** 同时设置收发两个方向的网络接入码。输入其十六进制数字；**上** 和 **下** 让最后一位在 0-9 和 A-F 之间步进，
  因此要输入 1A5，输入 1、9、**上**、5。F7E 接收所有 NAC。通话组为**发射联系人**，你的单元 ID 为**自身 ID**。
- 在“模式”上按 **OK** 依次切换到 NXDN（在支持的电台上）、FM、DMR，再回到 P25 且设置保持原样，因此误按不会有损失。
  把信道保存为另一种模式会删除其 P25 设置：电台会先询问（“存为FM？”、“存为DMR？”，NXDN 时为“未保存的更改”），
  默认为“否，继续编辑”。**存为新信道**会保持 P25 信道不变。
- 扫描会在 P25 信道上停留，并在你会在那里听到的呼叫上保持。双守候可以把它作为 A 或 B。

### P25 集群信道

在支持 P25 集群的电台上，信道可以属于一个 P25 集群系统（Phase 1 话音信道）。系统（其控制信道、身份和你的单元 ID）
及其信道（每个一个通话组）来自在电脑上写入的电台频率（[编辑器中的 P25 与 NXDN](04-programming.md#p25-and-nxdn)）。
新系统为仅收听。信道的设置把模式显示为“P25T”。

| 主屏幕显示 | 电台正在做什么 |
|---|---|
| 搜索中 | 依次尝试系统的控制信道 |
| 等待呼叫 | 在控制信道上，等待发往该信道通话组的呼叫 |
| 监听 TG 201 | 在某次呼叫的话音信道上。呼叫结束后回到控制信道 |
| 正在注册 | 发射已打开：正在向系统注册并加入通话组 |
| TG 201 | 已注册。PTT 向系统请求话音信道 |
| 请等待、等待中 | 正按住 PTT，请求已交给系统。主屏幕显示发射时开始讲话 |
| 已拒绝、注册已拒绝 | 系统拒绝了请求或注册 |

- 设为仅收听的系统、设为仅接收的信道，或没有单元 ID 或通话组的信道从不发射：PTT 显示“仅接收”。
- 只有在信道设为跟随系统的所有通话组时，才会跟随发往其他通话组的呼叫。
- 电台不跟随发给单个单元的呼叫、紧急呼叫或 Phase 2（TDMA）话音信道。
- 扫描会跳过这些信道，双守候也不使用它们：集群信道改为跟随其系统。

### VFO 中的 NXDN

在支持 NXDN 的电台上，NXDN 是 VFO 的模式之一，位于 P25 之后（“VFO: NXDN”）。它是 9600 bit/s（12.5 kHz）或
4800 bit/s（6.25 kHz）的 NXDN 常规语音，使用电台的 DMR 语音编解码器。

- 它在所有无线接入号（RAN）上收听发往所有组的明文语音呼叫。加密呼叫保持静音。
- PTT 以 9600 bit/s、RAN 1 向组 1 发送语音呼叫，在电脑设置其他 ID 之前以单元 1 发送。
- 主屏幕显示“NXDN”、PTT 呼叫的对象（“TG 1”）、发送的 RAN 和速率（“RAN 1 9600”）。通话期间，它显示谁在呼叫以及呼叫发往何处，
  或呼叫不播放的原因。FM 的亚音和带宽磁贴显示“仅 FM：这是 NXDN”。
- 速率、RAN、单元 ID 和组只能从电脑更改（`rfoundry_debug.py radio nxdn`），更改持续到你关闭电台。
- 有些电台只发射 NXDN 或只接收 NXDN（[功能矩阵](../feature-matrix.md)）。只能接收的电台在按 PTT 时显示“此模式：仅接收”。

### NXDN 信道

NXDN 信道可以来自在电脑上写入的电台频率（[编辑器中的 P25 与 NXDN](04-programming.md#p25-and-nxdn)）、另一台电台共享的区域、
VFO（在 NXDN 中打开**信道**，选择**用当前新建**并保存），或任何信道：在其“模式”上按 **OK** 直到显示 NXDN，设置 RAN 和速率并保存。
改为 NXDN 的信道初始为 RAN 1、9600 bit/s。信道保存速率、RAN、静噪和组（某联系人有该组时；否则为组 1）。

- 主屏幕的显示与 VFO 中相同。信道的设置把模式显示为“NXDN”。
- 在“模式”上按 **OK** 依次切换到 FM、DMR、P25（在支持的电台上），再回到 NXDN 且设置保持原样。把信道保存为另一种模式会删除其
  NXDN 设置：电台会先询问（“存为FM？”、“存为DMR？”，P25 时为“未保存的更改”）。
- **RAN**（0-63）和**速率**（9600 或 4800 bit/s）位于信道的设置中，还有组（**发射联系人**）和你的单元 ID（**自身 ID**，最大 65519）。
  RAN 0 接收所有 RAN。静噪只能从电脑更改。
- 扫描会在 NXDN 信道上停留，并在你会在那里听到、且速率为电台能接收的呼叫上保持。双守候可以把它作为 A 或 B。

### 离开 VFO

按 **OK**、**4**，然后再次在 VFO 行上按 **OK**（“返回信道”）。或选择一个区域或信道。**VFO/MR** 键或设为“VFO/信道”的侧键
会回到你之前所在的信道。

## 航空波段与调频广播

有些电台还可以以 AM 接收航空波段，并接收调频广播电台（[电台参考](23-radios.md)）。没有需要选择的模式，也没有菜单：由频率决定。

| 调到 | 你听到 |
|---|---|
| 108 到 137 MHz | 航空波段，AM。主屏幕显示“航空 AM”和静噪级别，并以“AM”代替“FM” |
| 广播波段（大多数接收机上为 65 到 108 MHz） | 调频广播，通过电台的广播接收机。主屏幕显示“调频广播” |

在 VFO 中调到这些频率（输入 **1** **1** **8** **1** 或 **0** **8** **8** **1**，然后按 **OK**）。DMR VFO 在这些频率上切换为 FM
并保持 FM；在这些波段中不能选择 DMR。要保留一个电台，在信道列表中使用**用当前新建**（或在信道编辑器中输入接收频率）：
信道变为仅接收，可以直接保存。其“模式”在航空波段显示 AM，在广播波段显示 FM，在其上按 OK 不会切换到 DMR；亚音行被隐藏。
在电台频率中编程在该频率上的信道也可以使用，即使它保存为 DMR。两个波段都是仅接收：PTT 显示“航空波段：仅接收”或
“广播：仅接收”，电台不发射。亚音会被忽略。

在电台频率编辑器中，接收频率位于这些波段之一的信道，在你输入频率时会被设为**仅接收**，其发射频率跟随接收频率，
模式显示为“AM（航空波段）”或“调频广播”。如果这些波段中的信道不是仅接收或是 DMR，问题列表会发出警告。

在航空波段中，静噪的工作方式与任何 FM 信道相同。无论静噪级别如何，广播电台都会播放，因此信号衰落的电台不会被切断，
屏幕显示正在接收。LED 保持熄灭：电台广播不是呼叫。静噪只用于让扫描停在电台上：扫描运行时，广播波段在电台之间保持安静。

在广播波段中，旋钮和 **上** / **下** 以 200 kHz 步进，落在奇数的十分位上（88.1、88.3 ... 107.9），这是美洲电台所在的位置。
要以 100 kHz 步进，把**设置 > 通话与收听 > 调频广播步进**设为 100 kHz。无论哪种方式，你都可以输入任意频率，例如 90.2。
在航空波段中，**自动**以 25 kHz 步进；对于窄信道，把 VFO 步进设为 8.33 kHz。

## 电台无法使用的信道

超出电台频段的信道不发射（“超出……”）。仅接收信道的通话目标显示“仅接收”。
