# 紧急

不要依靠告警和紧急呼叫保障安全。

## 他人宣告紧急时

电台听到发给你或你所收听通话组的紧急告警，或播放标记为紧急的呼叫时，会打开紧急屏幕并播放告警音（约 1 秒的颤音）。
有振动马达的电台还会振动四次，除非关闭了**设置 > 声音 > 振动**。屏幕显示“紧急呼叫”和该台站的名称或 ID。

<img src="../ux/screens/160x120i5/emergency.png" width="200" alt="收到紧急">

| 按键 | 作用 |
|---|---|
| **OK** | 确认：关闭屏幕（“紧急呼叫已确认”） |
| **#** | 关闭屏幕，并打开对该台站的操作：与其通话、个呼，或检查其电台 |
| **返回** | 隐藏屏幕 |

同一台电台在其上次活动后 30 秒内再次发出的紧急（重复的告警、随后的呼叫）不会触发第二次告警。

## 宣告紧急

电台可以发送紧急告警，并开始带热麦的紧急呼叫。默认情况下，它发送 3 次告警。然后它让发射机发射 10 秒，
因此收听的人无需你按 **PTT** 就能听到你。在你取消之前，你发起的每次呼叫都带有紧急标志，并发往信道的通话目标。
在热麦期间按 **PTT** 会接管这次发射。

1. 按住**功率级别**键 1.5 秒。屏幕显示“紧急已发：再长按取消”。
2. 要取消，再按住该键 1.5 秒。屏幕显示“紧急呼叫已取消”。

短按同一个键仍会更改功率级别。在 1.5 秒前松开从不会发起紧急。在无法发起紧急的情况下（见本页末尾），电台显示“紧急需 DMR 信道和 ID”。

只有带**功率级别**键的电台才能用按键宣告紧急。[按键角色](23-radios.md#key-roles)说明哪些电台有该键。

开发者也可以通过调试链路发起和取消紧急：

```
tools/rfoundry_debug.py data emergency start
tools/rfoundry_debug.py data emergency cancel
```

模式（仅告警、先告警后呼叫、仅呼叫）、目标、告警次数和热麦时间也以同样方式设置（`tools/rfoundry_debug.py data em-settings`）。
详情见 [DMR 紧急](../spec/dmr-emergency.md)。

在 FM 信道或 FM VFO 上、在仅接收信道上、在热点模式下，或没有 DMR ID 时，无法发起紧急。DMR VFO 与 DMR 信道相同。
