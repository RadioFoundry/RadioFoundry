# 首次启动

## 开机

用电源开关打开电台。在手台上，电源开关就是音量旋钮，顺时针转过“咔嗒”一声即可。各电台的开关位置见[电台参考](23-radios.md)。启动画面显示约一秒，然后电台进入主屏幕。启动画面期间按下的键会被忽略。

启动画面显示 RadioFoundry 标志，以及电台频率中的两行启动文字。底部显示电台型号和固件版本：发行版名称，例如 v26.11（发布的年月），或发行版之间的构建所使用的提交。启动文字每行 16 个字符，在电台频率中设置，例如你的呼号和姓名。

<img src="../ux/screens/160x120i5/boot.png" width="200" alt="启动画面">

关闭电台时，再次使用电源开关。在手台上，逆时针转动音量旋钮直到“咔嗒”一声。见[关机](16-battery-and-power.md#turning-off)。

## 新安装后的信道

RadioFoundry 从电台的 SPI 闪存读取电台频率，其布局与电台频率编辑器和 qdmr 写入的一致。电台频率保存信道、区域、联系人和你的 DMR ID。当 RadioFoundry 在其中找不到信道时，会使用六个内置的 FM 单工信道：

| 信道 | 频率 | 带宽 |
|---|---|---|
| Simplex 145.500 | 145.500 MHz | 25 kHz |
| Simplex 146.520 | 146.520 MHz | 25 kHz |
| Simplex 146.550 | 146.550 MHz | 25 kHz |
| Simplex 433.500 | 433.500 MHz | 12.5 kHz |
| Simplex 446.000 | 446.000 MHz | 12.5 kHz |
| Simplex 446.500 | 446.500 MHz | 12.5 kHz |

在这些频率上发射之前，请确认它们在你的地区是合法的。**设置 > 高级 > 电台频率**会显示电台使用哪些信道：“内置信道”或“由 CPS 写入”。

运行过原厂固件的电台仍保留该固件的电台频率。RadioFoundry 启动时会检查电台频率。当它不是 RadioFoundry（开源固件）的电台频率时，电台会忽略它并使用内置信道。此时**设置 > 高级 > 电台频率**还会显示“其他固件电台频率：已忽略”。不会擦除任何内容：电台频率编辑器仍可读取并转换它。写入一份电台频率即可替换它。

第一次在电台上保存内容（信道、联系人、区域、你的 DMR ID）时，会先在**旧电台频率**屏幕上询问：

| 选项 | 作用 |
|---|---|
| 取消 | 不保存任何内容。这是默认选项，返回键效果相同 |
| 新建 | 新建一份空的 RadioFoundry 电台频率并保存你的更改。旧电台频率中的信道、联系人、DMR ID 和电台名会被擦除。请先备份 |
| 仍然使用 | 不擦除任何内容，按原样使用旧电台频率。你的更改不会被保存：请重新操作 |

“仍然使用”会被记住，直到向电台写入电台频率或执行恢复出厂设置。

## 为电台编程

在项目网站上用电台频率编辑器编写信道、区域、联系人、通话组列表和你的 DMR ID（[为电台编程](04-programming.md)）。qdmr 是另一种选择。大多数设置也可以在电台上更改（[设置](17-settings.md)）。信道、联系人和 DMR ID 来自电台频率。

DMR 需要你的 DMR ID。没有它，电台会拒绝在 DMR 信道上发射，并显示“电台频率中无 DMR ID”。**设置 > 我的电台 > DMR ID 和名称**会显示电台现有的 ID，并可在电台上设置：它会写入电台频率。

## 安装后的检查

1. **设置 > 我的电台 > 关于**（也在**高级**下）会显示“RadioFoundry”、你刷入的版本和电台型号。其下还会列出作者，以及固件中各项内容的许可证。
2. 在 FM 信道上，长按**监听**打开静噪。你会听到噪声。这说明接收机和音频通路工作正常。
3. 在 DMR 信道上，如果编解码器未合并，主屏幕底行会显示“无编解码器：语音关闭”。见[安装，无编解码器](02-installing.md#no-codec-no-codec-voice-off)。
4. 更改一项设置，例如**设置 > 显示 > 亮度**。关闭电台再开机。确认设置仍然保留。若未保留，见[故障排查](20-troubleshooting.md)中的“设置未保存”。
