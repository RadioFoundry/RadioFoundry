# 热点模式

在热点模式中，电台作为 DMR 调制解调器，供运行 MMDVMHost、Pi-Star 或类似主机的电脑使用。主机把电台接入 DMR 网络
（BrandMeister、TGIF 等）。电台在一个频率上承载与附近电台之间的呼叫。电台通过串口使用 MMDVM 调制解调器协议。
有 USB 的电台使用 USB 串口；没有 USB 的电台使用编程线（[电台参考](23-radios.md)）。

有些电台的默认镜像不含热点模式。这些电台上**工具 > 热点**为灰色。[功能矩阵](../feature-matrix.md)列出了这些电台。

## 你需要什么

- 一台装有 MMDVMHost 的电脑（Linux、macOS），或树莓派上的 Pi-Star 类镜像。
- 电台的 USB 线，或没有 USB 的电台的编程线。
- 不需要编解码器：电台直接转发 DMR 帧，不解码语音。
- **设置 > 连接 > 允许热点**为开（默认）。

## 设置 MMDVMHost

把 MMDVMHost 的调制解调器指向电台的串口，并作为单工 DMR 热点运行。`MMDVM.ini` 中重要的部分：

```
[General]
Duplex=0

[Info]
RXFrequency=438800000
TXFrequency=438800000

[Modem]
Protocol=uart
UARTPort=/dev/ttyACM0
UARTSpeed=115200

[DMR]
Enable=1
ColorCode=1

[DMR Network]
Enable=1
Slot1=0
Slot2=1
```

- 在 USB 上，Linux 的端口是 `/dev/ttyACM0`（或下一个编号），macOS 上是 `/dev/cu.usbmodem...`。电台的 USB ID 是 1FC9:0094。
- 收发使用同一频率，且位于电台的频段内（[电台参考](23-radios.md)）。
- 电台只使用时隙 2：启用网络时隙 2，禁用时隙 1。
- 在 USB 上，电台忽略波特率。115200 即可。
- 其他模式（D-Star、YSF、P25、NXDN、POCSAG、FM）保持关闭。电台会拒绝它们。电台接受 POCSAG，但从不发射。

在 Pi-Star 类镜像中，选择电台串口上的 USB MMDVM 调制解调器，并使用上述设置。

电台向主机报告自己为“RadioFoundry”、电台型号（例如“RadioFoundry XR-100UV”）以及固件版本。

## 启动

当主机打开端口并发送第一个 MMDVM 请求时，电台会自行进入热点模式。屏幕切换到热点屏幕。

<img src="../ux/screens/160x120i5/hotspot.png" width="200" alt="热点屏幕">

热点屏幕显示：

- 状态：STARTING、HOTSPOT、附近电台讲话时的 RX RF，或网络呼叫发出时的 TX NET。
- 频率、色码和功率。
- 当前或最近一次呼叫，含来源（“RF”或“Net”）、呼叫者和通话组。

**OK**、**6**（工具）、**3**（热点）显示如何启动热点模式。运行期间，该页面有“停止热点”行。

## 热点模式期间

- **\*** 在热点屏幕和诊断页面之间切换。
- **PTT** 不发射（“热点模式：PTT 关闭”）。
- 其他任何键显示“热点开：OK 停止”。
- 如果主机请求 CW 标识，电台以 FM 在热点频率上发送摩尔斯码，然后回到 DMR。摩尔斯码为每分钟 20 词、800 Hz。

## 停止

发生以下任一情况时，电台离开热点模式并返回其信道：

- 你按 **OK** 或长按 **返回**（“热点已停止”）。
- 主机关闭端口，或你拔下 USB 线。
- 主机 20 秒内没有发送任何内容。

要完全阻止电台进入热点模式，关闭**设置 > 连接 > 允许热点**。

## MMDVM SFR（单频中继）

在 MMDVM SFR 中，热点把在时隙 1 上听到的呼叫在同一频率的时隙 2 上重发。它还把呼叫发往网络。附近处于直通模式的电台两者都能听到。
哪些电台支持，见[功能矩阵](../feature-matrix.md)。

主机以双工方式运行并令收发频率相同（`Duplex=1`，`RXFrequency` = `TXFrequency`），即开启 MMDVM SFR。设为 `Duplex=0`
或不同频率则关闭它。

## 独立 SFR

信道可以是单频中继，或使用单频中继的电台，无需主机。在电台频率编辑器中设置信道的 SFR 角色。信道必须只有一个频率（接收 = 发射）。

VFO 也可以有角色，无需更改电台频率。在 DMR VFO 中，打开**工具 > 单频中继**：

- **角色**依次切换：关、用户、用户 (ERDM)、中继台、中继台（ERDM 式）。
- **入站时隙**在 TS1 和 TS2 之间切换。

VFO 保留其角色，关机后也是如此。角色只在 DMR 且只有一个频率时有效：有发射频差时，页面会说明角色已关闭。
VFO 的色码在两个时隙上都是中继台的色码。**复制到 VFO** 会把信道的角色一并带过来。

| 角色 | 电台的行为 |
|---|---|
| 中继台（Rpt、Rpt Moto） | 把在入站时隙上听到的每个呼叫在另一时隙上重发。**PTT** 关闭（“中继信道”）。转发时电台显示接收，发送时红色 LED 点亮。发射被禁止、电量严重不足，或扫描或双守候运行时，该信道作为普通信道工作。**设置 > 通话与收听 > 单频中继 CW ID** 使中继台在有通话后每 5 到 30 分钟以摩尔斯码发送呼号 |
| 用户（User、ERDM） | 在入站时隙上与中继台同步通话，并播放中继台转发的呼叫副本。**设置 > 通话与收听 > 单频中继接收**还可取用通话者自己的副本：先到的那份，或两份都用，每个损坏帧取自另一份（双路接收） |

同一频率上的所有电台必须使用相同的入站时隙：两种配置不能共用一个频率。**工具 > 单频中继**显示信道的角色、其时隙，
以及中继台正在做什么。时序、时隙以及各角色如何工作，见[单频中继](../spec/sfr.md)。

## 两台电台组成双工中继

两台电台各自接在一台电脑的不同端口上，作为一个全双工中继工作。一台接收，另一台发射。两者的镜像都需要分离双工。
哪些电台提供，见[功能矩阵](../feature-matrix.md)。电脑运行 `tools/split_duplex_host.py`。详情见[分离双工](../spec/split-duplex.md)。
