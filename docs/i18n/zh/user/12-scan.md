# 扫描与双守候

哪些电台有扫描和双守候，见[功能矩阵](../feature-matrix.md)。

## 开始和停止

| 开始 | 停止 |
|---|---|
| **OK**、**6**（工具）、**1**（扫描） | 在主屏幕上按 **返回** |
| 设为**扫描**的侧键（**设置 > 按键**） | 再按同一个键 |

在信道上，电台扫描当前区域（“正在扫描区域”）。在 VFO 中，它扫描 VFO 频率所在的频段（“正在扫描频段”）。
状态行显示 SCAN，信道名称随扫描移动而变化。

扫描需要至少一个可前往的其他信道。在热点模式下或你发射时，扫描不运行。

如果双守候正在运行，开始扫描会停止双守候。电台留在所选信道上，并从那里开始扫描。

## 扫描如何移动

- 扫描从开始的信道起按顺序访问区域中的信道。它跳过空位置和电台频率中标记为跳过的信道。FM、DMR、P25 和 NXDN 信道可以混合。
  P25 集群信道会被跳过。
- 在每个信道上它收听 150 ms。FM 信道在静噪打开时（如果信道需要亚音，则须带有该亚音）停止扫描。DMR、P25 或 NXDN 信道在电台播放呼叫时停止扫描。
  有信号时，它最多收听 1.5 秒，等待它会播放的呼叫。
- 开始扫描前打开[数字监听](09-dmr.md)，可在发往任意通话组的呼叫上停下，而不仅限于信道的通话组和接收组列表。
  数字监听在每个信道上以及扫描结束所在的信道上都保持打开。扫描期间在 DMR 信道上按**监听**，可在剩余的扫描中关闭或打开它。
- 有信号时扫描保持。信号结束 2 秒后继续，信号恢复时留下。
- 长按**监听**暂停扫描。

## 扫描期间

| 按键 | 作用 |
|---|---|
| **PTT** | 停在最后让扫描保持的信道上并在那里通话。扫描仍在搜索时，回到开始的信道并在那里通话 |
| **#** | 打开让扫描停下的信道的扫描操作 |
| **返回** | 停止扫描 |
| 自己切换信道、区域或 VFO | 在你切换到的位置结束扫描 |

<img src="../ux/screens/160x120i5/scan_actions.png" width="200" alt="扫描操作">

扫描操作：

| # | 操作 | 作用 |
|---|---|---|
| 1 | 暂时跳过信道 | 在扫描停止前跳过该信道（“扫描停止前跳过”） |
| 2 | 留在此处 | 在此信道上停止扫描 |
| 3 | 总是跳过 | 始终为灰色。请在 qdmr 中编辑扫描列表 |

## 双守候

双守候在两个信道 A 和 B 上收听，你在其中一个上通话。每个都可以是任意区域中的任意信道，或 VFO。
它是两个频率，而不是同一 DMR 频率上的两个时隙。

- **A** 是你开始时所在的信道。**B** 是你添加的信道。第一次时，B 是区域中的下一个信道。
- 其中一个是**选中**的信道。**PTT** 在其上通话。上、下、旋钮、快速设置、通话目标和菜单都作用于它，与普通主屏幕上相同，
  即使电台正在收听另一个信道。你发射之后双守候继续进行。
- 电台在两个信道之间来回切换时，每个信道都保留其暂时更改（功率、静噪、亚音、通话目标等）。
- 电台只有一个接收机，因此它在 A 和 B 之间交替。电台在一个信道上时，可能错过另一个信道上的呼叫。有两个接收机的电台可以同时收听两者，
  并在每个信道上同时显示呼叫。各电台的情况见[各电台的双守候](23-radios.md#dual-watch-on-each-radio)。
- A 或 B 可以是 P25 或 NXDN 信道，但不能是 P25 集群信道。在有两个接收机的电台上，第二个接收机不接收 P25 或 NXDN：
  未选中的信道为此类信道时，电台改为交替收听。

### 启动双守候

1. 转到你想作为 A 的信道。
2. 按 **\***，然后按 **7**（**双守**快速磁贴）。第一次时，B 是 A 所在区域中的下一个信道（在只有一个信道的区域中：
   下一个区域的第一个信道，或 VFO）。之后它从上一次的 B 开始。按两下即可。长按 **A/B** 键效果相同。

主屏幕显示两个信道，A 在上、B 在下，状态条显示“双守”。

如果关机时双守候是打开的，开机时它会再次启动。电台关机时也会记住上一次的 B。它按信道编号重新找到 B：先在 A 的区域中找，
再在第一个包含它的区域中找。如果该信道已从电台频率中删除，B 再次为下一个信道。

如果你在选中 B 时停止双守候，电台留在 B 上。下次启动时守候同样的两个信道。

### 更改 B

选中 B（**A/B** 键，或 **#**、**1**），然后像在主屏幕上一样更改其信道：**上**、**下**、旋钮、数字、查找、区域或 **VFO** 键。
A 也一样。

或按 **#**、**3**（改 B）打开选择器。列表显示你所在区域的信道，带有其频率和模式。按信道的编号、输入其名称的一部分，
或移到其上并按 **OK**。你所在的信道显示为灰色并标有“A”：它不能作为 B。

<img src="../ux/screens/160x120i5/dual_pick.png" width="200" alt="选择 B：区域的信道">

要选择另一个区域中的信道或 VFO，移到**区域**行并按 **OK**。列表先显示 **VFO**，然后是各区域。选择一个区域查看其信道，
或选择 **VFO** 守候一个 VFO 频率。

<img src="../ux/screens/160x120i5/dual_zones.png" width="200" alt="B 的区域：VFO 或某个区域">

### 读懂主屏幕

<img src="../ux/screens/240x320/home_dual_rx_b.png" width="200" alt="双守候主屏幕，B 上有呼叫进入">

每个信道有一个字母、名称、**PTT** 的通话对象（通话组，FM 上为频率）、频率和所在区域。选中的信道在其字母下有一个箭头。

| 你看到 | 含义 |
|---|---|
| **PTT**、填充的字母和箭头 | 这是选中的信道：**PTT** 在这里通话 |
| **TX**（红色）和“正在通话于 A” | 你正在 A 上发射 |
| **RX**（绿色）和“正在接收 B” | B 上有呼叫进入。该信道显示谁在呼叫，该行右侧显示 RX |
| “B Joe Smith TG 91 10s ago” | 最近的呼叫，最新的在前，带有其信道 |
| “收到 7s ago”（在信道上） | 该信道上最近一次呼叫结束的时间，在放得下的位置显示：最新的呼叫为琥珀色，另一个信道为暗色 |
| **忙**（绿色，在信道上） | 电台正在另一个信道上等待回复，并在这里发现了信号。尚未播放：等待结束后电台会转到这里 |
| “# 1 在 B 通话” | 最近 10 秒内 B 上有呼叫进入。**#**、**1** 在那里回话 |
| “# 1 回 A” | 回话已打开，且 **PTT** 在 B 上（见下文） |

默认情况下，另一个信道上的呼叫从不移动 **PTT**。由你选择。

### 呼叫之后的等待

电台只有一个接收机，因此它在 A 和 B 之间切换。呼叫结束时，它在该信道上停留 1 秒，以便听到回复。等待期间，它短暂查看另一个信道。
那里的呼叫显示为**忙**，但不会打断：等待结束后，电台转到那里。用**设置 > 通话与收听 > 双守候延时**更改等待时间（0.5 秒到 5 秒）。
较短的等待能更快发现另一个信道；较长的等待能保留更多开始较晚的回复。

### 回话

打开**设置 > 通话与收听 > 双守候回话**（默认关闭），**PTT** 就会跟随呼叫。另一个信道上的呼叫结束时，该信道成为选中的信道
（“在 B 回话”），因此 **PTT** 在那里应答。每次回复以及那里的每次呼叫都会让 10 秒计时器重新开始。计时结束后，选中的信道恢复原状
（“在 A 通话”）。**#**、**1**、**A/B** 键或 **左** / **右** 会立即返回。回话期间，提示行显示“# 1 回 A  返回 停止”。

<img src="../ux/screens/240x320/home_dual_talk_back.png" width="200" alt="在 B 回话">

### 在 B 上通话

按 **#**、**1**（“在 B 通话”）。B 现在是选中的信道。在有左 / 右键的电台上，**右** 选中 B，**左** 选中 A。按一下 **A/B** 键也会切换，
任何设为 **A/B** 的侧键也一样（设置 > 按键）。双守候关闭时，**A/B** 键只显示“请先开双守候”。按住 **PTT** 讲话。
你松开后守候继续。

<img src="../ux/screens/160x120i5/home_dual_on_b.png" width="200" alt="选中 B 的双守候主屏幕">

### 更改 A 或 B

在主屏幕上按 **#**。操作为：

| # | 操作 | 作用 |
|---|---|---|
| 1 | 在 B 通话（或 A） | 选中另一个信道 |
| 2 | 改 A | 打开 A 的选择器 |
| 3 | 改 B | 打开 B 的选择器 |
| 4 | 来电方 | 最近来电方的操作（听到呼叫之前为灰色） |
| 5 | 停止，留在 A（或 B） | 在选中的信道上结束双守候 |

<img src="../ux/screens/160x120i5/dual_actions.png" width="200" alt="双守候操作">

一个信道不能同时作为 A 和 B。更改 A 或 B 会清除为其列出的呼叫。

**上** / **下** 和旋钮让选中的信道在其区域中移动，并跳过另一个信道。在 VFO 上它们步进频率。在没有其他信道可去的区域中，
电台会说明这一点（“本区域仅一个信道”）。

你在查找、信道或区域中选择的信道成为选中的信道；选择另一个信道则选中它。**VFO** 键把选中的信道放到 VFO 上，再按一次回到其信道。
复制到 VFO 把选中的信道复制到 VFO 中。A 和 B 各有自己的 VFO，因此两者都可以是不同频率上的 VFO；电台会记住两者。
要设置某个 VFO 窗格的频率，选中它并输入频率。输入时数字显示在该窗格上；**返回** 删除一位。按 **OK** 或 **#** 调谐。
双守候在新频率上继续。没有正在输入的频率时，**#** 打开双守候操作。热点模式和电台频率写入不会停止双守候。

区域键（**上一区域**和**下一区域**）把选中的信道移到上一个或下一个区域，落在该区域中不是另一个信道的第一个信道上
（“A 区域： Simplex”）。双守候继续。**主区域**键把它移到第一个区域。如果 **上** / **下** 设为**区域**（设置 > 按键），
它们的作用相同，旋钮仍切换信道。

### 停止双守候

在主屏幕上按两次 **返回**。第一次按会显示“再按返回停止双守候”，因此误按不会停止它。如果你输入了频率或暂时更改了设置，
**返回** 先清除这些。电台留在选中的信道上（“双守候关：在 B”）。以下操作也会停止它：**\***、**7**；长按 **A/B** 键；**#**、**5**；
以及设为**双守候**的侧键。开始扫描（**OK**、**6**、**1**，或**扫描**键）会停止它，并留在选中的信道上。其他操作都不会停止它。
如果电台无法继续使用某个信道（例如它被删除了），主屏幕会说明电台在哪里：“双守候关：在 COUNTY DMR”。

### 按键

| 按键 | 作用 |
|---|---|
| **PTT** | 在选中的信道上通话 |
| **#** | 双守候操作 |
| **\*** | 选中信道的快速设置 |
| **上** / **下**、旋钮 | 选中的信道在其区域中移动（VFO：一个步进） |
| **A/B** 键（短按，或设置 > 按键）、**左** / **右** | 另一个信道 / A / B。双守候关闭时，**A/B** 键显示“请先开双守候” |
| **上一区域**、**下一区域**、**主区域** | 选中的信道转到另一个区域 |
| **监听**（按住） | 在选中的信道上打开静噪。双守候在那里等待，直到你松开 |
| **双守候**键（设置 > 按键）、长按 **A/B** 键 | 启动（使用上一次的 B）和停止 |
| **VFO** | 把选中的信道切到 VFO，再切回 |
| **返回**，按两次 | 停止，留在选中的信道上 |

启动双守候会停止区域扫描。打开**大字体**时（设置 > 显示），主屏幕每个信道显示一行，选中的信道用箭头标出。
