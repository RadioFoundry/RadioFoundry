# 安装

用项目网站 [radiofoundry.org](https://radiofoundry.org/flash/index.html) 上的**网页安装器**安装、更新、备份和恢复
RadioFoundry。它在基于 Chromium 的浏览器（Chrome、Edge）中运行，无需安装任何东西。你载入其中的文件不会离开你的电脑。
本章的任何操作都不会改动电台的校准。

命令行工具 **rfoundry** 可在终端中完成同样的工作。它适用于脚本、无法与电台通信的浏览器，或本地构建。
详情见[命令行 rfoundry](#advanced-rfoundry-on-the-command-line)。

各电台之间的差异（原厂固件文件、进入引导程序的按键、安装方式）见[电台参考](23-radios.md)中你的电台的“安装”一节。
要把电台频率从制造商固件迁移过来，见[从原厂固件迁移](18-moving-from-stock.md)。

## 你需要什么

| 项目 | 说明 |
|---|---|
| 一台装有 Windows、macOS 或 Linux 的电脑，或一台 Android 手机或平板 | 在 Android 上，使用 Chrome，并用 USB OTG 转接头连接线缆。详情见[常见问题](21-faq.md#can-i-use-a-phone) |
| 一个基于 Chromium 的浏览器 | 用于网页安装器 |
| 你的电台的原厂固件文件 | 制造商提供的文件，版本需被安装器识别。你的电台的“安装”一节会说明文件名和获取位置 |
| 电台的 USB 线或编程线 | 随电台附带的线缆 |

发行版固件包含除 AMBE 编解码器之外的一切。安装器要么保留电台中已有的编解码器，要么从你电脑上的原厂固件文件中取出并写入电台。
原厂文件还为安装器提供电台引导程序所需的密钥。电台运行 RadioFoundry 后，安装器改为从电台读取密钥。
安装器用 SHA-256 哈希校验每个文件，并拒绝未知文件。

安装前，先用你现在使用的程序（制造商的 CPS 或 qdmr）备份电台的电台频率。RadioFoundry 使用的电台频率布局与原厂固件不同。
以后若要回到原厂固件，需要这份备份。网页安装器自带的备份也包含它。

## 用网页安装器安装

要更新已运行 RadioFoundry 的电台，见[更新 RadioFoundry](#updating-radiofoundry)。

1. 打开[网页安装器](https://radiofoundry.org/flash/index.html)，选择**安装**。
2. 在**电台**步骤，选择你的电台。
3. 在**构建**步骤，选择功能：

   - **完整**包含电台支持的全部功能。**业余**和**商用**是较小的预设。**自定义**可逐个选择功能。页面会标出电台不能有的功能。
   - **电台语言**设置电台启动时使用的语言。构建包含页面的语言时，它预设为页面的语言。如果你选择构建未包含的语言，
     安装器会把它加入构建。以后可在电台上的**设置 > 显示 > 语言**中更改语言。
   - 浏览器请求的语言不在构建中时，页面会提议加入它。
   - 构建对电台来说过大时，页面会说明超出多少。在**自定义**中关掉一些功能，或选择较小的构建，然后重新构建。

   自定义构建在你继续时生成，用时不到一分钟。
4. 在**当前固件**步骤，说明电台现在运行什么：

   | 选项 | 何时选择 |
   |---|---|
   | **RadioFoundry** | 电台运行 RadioFoundry。连接电台并开机；安装器读取已安装的版本 |
   | **原始固件** | 出厂时安装的固件 |
   | **其他开源固件** | 另一个开源固件项目，例如 OpenGD77 系列之一 |
   | **其他 / 不确定** | 任何其他固件，或你不知道电台运行什么 |

   安装器只在需要编解码器或密钥时才要求原厂固件文件。如果你选择 **RadioFoundry**，而电台运行的是 OpenGD77 系列固件，
   安装器会说明这一点，并改为提供**其他开源固件**。没有调试链路的 RadioFoundry 构建也会得到同样的回答。

   在某些电台上，**原始固件**和**其他 / 不确定**会在写入任何内容之前提供额外步骤：

   - **立即备份**（推荐）。连接正常开机的电台，选择**全部内容**（数分钟）或**仅信道和设置**（不到一分钟）。
     安装器读取电台的出厂数据、程序存储器的开头部分和存储芯片，在你的电脑上保存为 `.zip` 文件，然后重启电台。
     不会向电台写入任何内容，也不会向任何地方发送任何内容。在更新模式下，电台提供的内容较少（存储芯片的一部分）；
     安装器会说明这一点，安装可以从那里继续。请妥善保管该文件：它包含你的电台的校准。
   - **读取固件版本**，用于 RadioFoundry 无法总是区分硬件版本、但能区分原厂固件版本的电台。连接正常开机的电台，
     不要处于引导程序。读取不会改动电台。安装后，安装器把硬件版本保存到电台。如果电台已保存了不同的版本，
     安装器会同时显示两者并保留你的版本（**设置 > 高级 > 硬件**）。这一步是可选的。电台无法检测自己的版本时，
     安装器会在安装后询问，电台会在主屏幕上显示提醒，直到你设置为止。在此之前电台不会发射。
5. 在**备份**步骤，让安装器保存一个备份文件（`.zip` 文件），其中包含固件、信道和设置以及校准。请保留它。
   无法先读取原厂固件时，安装器会在安装后立即备份电台，先于其他任何改动。

   在通过编程线安装的电台上，线缆较慢，因此安装器会显示每一部分所需的时间：

   - 程序存储器是必需的，除非你改用原厂固件文件。
   - **所有信道和设置**是可选项，默认关闭。安装器从不改动它们，而读取整个数据存储器可能需要许多分钟。
   - 如果你有电台的原厂固件文件，**改用原始固件文件**可在读取前或读取过程中跳过固件备份。
     安装器随后只读取编解码器区域，并在下一步从文件中取用编解码器。电台中的固件不会被备份，但原厂文件可以恢复它。

   没有固件备份或原厂固件文件时，安装器没有编解码器可写入电台。如果你跳过固件备份且未选择受支持的文件，
   **不装编解码器安装**是唯一的继续方式。安装器随后会在**安装**按钮上方警告：此次安装不包含 DMR 语音编解码器；
   FM 可用，但在你用受支持的制造商固件文件重新安装 RadioFoundry 之前，DMR 语音不可用。重新安装会保留你的信道和设置。
   按下**安装**时，对话框会再问一次：**返回并加入编解码器**回到选择文件的步骤，**仍然安装**则不带 DMR 语音安装。

   备份发现某个固件版本的编解码器尚未被 RadioFoundry 映射时，也会出现同样的选择。备份本身仍然完整；
   编解码器步骤会改为要求受支持的原厂固件文件。
6. 在**安装**步骤，在安装器提示时把电台置于引导程序。你的电台的按键见[电台参考](23-radios.md)。
   安装器写入变更的部分并重启电台。在安装器提示安装完成之前，不要拔下电台。
7. 在**校验**步骤，安装器读取电台报告的内容：它写入的版本，以及编解码器就位时的“DMR 语音已就绪”。
8. 在**信道**步骤，如果电台仍保留原厂固件的电台频率，安装器会把它迁移过来。它把电台频率转换为 RadioFoundry 布局，
   写入电台，再读回，并显示迁移了多少信道、区域和联系人。

   - 备份包含原厂电台频率时，这一步自动运行。
   - 如果你跳过了备份，安装器会先询问，因为在某些电台上，转换后的电台频率会替换原始字节。
   - 在把原厂电台频率与 RadioFoundry 的分开保存的电台上，无论有无备份，这一步都会运行。
     它只在替换电台上已有的 RadioFoundry 电台频率之前询问。
   - 更新 RadioFoundry 会跳过这一步。

   如果安装器无法读取、转换或写入原厂电台频率，它会说明这一点，电台将在没有信道的情况下启动。
   按[备份与恢复](#backing-up-and-restoring)所述转换备份。

在 Windows 上，引导程序需要安装一次驱动。详情见[Windows：引导程序驱动](#windows-the-bootloader-driver)。

然后继续阅读[首次启动](03-first-boot.md)。

### 从其他开源固件转来

在运行 OpenGD77 系列固件的电台上，安装器可以在安装前通过该固件备份整个电台，并从备份中取得更新密钥和语音编解码器。
这样就不需要原厂固件文件。安装器只在可行的电台上提供此选项。在其他电台上，它需要原厂固件文件。

1. 在**当前固件**步骤，电台已连接并开机时，选择**其他开源固件**，然后选择**检查电台**。选择 **RadioFoundry**
   也能发现其他固件。安装器会报告其版本。
2. 选择**备份并读取**。备份约需一分半钟。它只读取，不改动电台上的任何内容。请保留它保存的文件。
3. 查看安装器找到了什么：

   - 如果它找到了更新密钥和编解码器，继续即可。编解码器步骤使用你的电台中的编解码器。
   - 如果只找到其中一个或都没找到，请在编解码器步骤选择你的原厂固件文件。跳过备份或电台报告为其他型号时也是如此。

   其他固件的安装器可能把另一款电台固件中的编解码器放到了电台上，地址由它自己选择。备份会找到它。
   [电台参考](23-radios.md)中你的电台一节会说明哪些文件可用。
4. 照常通过引导程序安装。

如果备份过程中电台停止响应，请关机再开机，然后选择**继续读取**。备份会从停止处继续。**保存已读取的内容**会保留目前已读取的部分。

要回退，选择**恢复**并载入该备份，然后选择**之前的开源固件**。安装器写回固件，但不写回信道和设置。
如果缺少它们，请用该固件自带的编程软件写入。

### 更新 RadioFoundry

在 RadioFoundry 运行时正常启动电台，然后按以下步骤操作：

1. 在网页安装器中选择**更新**。
2. 连接电台并按**连接**。同一个端口列表会显示电台的 USB 端口和所有编程线。
3. 检查安装器显示的内容：电台、已安装版本、新版本，以及电台的构建（完整、业余、商用或自定义）。
   更新会安装新发行版的同一构建。

   - **编辑构建**打开构建步骤，以便你在更新前更改功能。
   - 预设构建会列出新发行版为其增加的功能。
   - 自定义构建会列出自其生成以来新增的功能。更新前为每一项选择**开**或**关**。
     如果你的某项功能现在需要一项新功能，安装器也会打开那项功能并将其列出。
   - 如果自定义构建的某项功能现在需要电台不具备的东西，安装器会列出它及其所需。按**禁用这些功能**在不带它们的情况下更新，
     或按**编辑构建**更改构建。
   - 固件过旧、无法报告其构建时，会进入构建步骤，从最接近的匹配开始。
   - 电台保留其启动语言。如果之前的一次更新可能误改了它，安装器会询问是保留该语言还是以英语启动。
4. 可选：打开**先保存备份**。它默认关闭，因为更新会保留信道、设置、校准和编解码器。
5. 按**更新**。安装器生成镜像、写入并核对版本。

电台会从 RadioFoundry 直接进入加载器：无需按住按键，也无需提供原厂固件文件。电台频率和设置会保留，
因为它们位于更新从不触碰的闪存中。在运行 RadioFoundry 的电台上，**安装**同样可用，只是会问所有问题。

### 备份与恢复

**备份**保存一个文件，包含电台的固件、编解码器、信道和设置。**恢复**用该文件写回整个电台、仅固件，或仅信道和设置。
恢复还可以用你的原厂固件文件把电台恢复为原厂固件。适用于你的电台的任意版本的制造商文件都可以，
不限于安装器为编解码器所需的那个版本。即使固件已损坏，从更新模式恢复也能成功。

**备份**会像安装一样询问电台现在运行什么：

- **RadioFoundry**：安装器通过调试链路读取电台。
- **其他开源固件**：安装器通过该固件读取电台，仅限它支持此操作的电台。
- 原厂固件：不在此处备份电台。请改为选择**安装**，它会在安装后立即备份电台。

每款电台都会列出所有备份选项及其耗时：程序存储器、出厂校准，以及所有信道和设置。

- **仅校准**（或**出厂校准**）只读取出厂校准。
- 在程序存储器中保存校准副本的电台上，该选项名为**程序存储器与校准**。
- 在把信道和设置保存在 NAND 存储器中的电台上，**所有信道和设置**会读取整个 NAND，可能需要数分钟。

恢复只写回程序存储器；备份中的校准和数据存储器仅作记录保留。不含程序存储器的备份无法恢复电台的原厂固件。
选择此类备份时，恢复会说明这一点，并提供**选择固件文件**：选择适用于你的电台、且版本受安装器支持的制造商固件文件。
电台完整的程序存储器转储同样可用，即使其固件版本尚未被映射。恢复会原样写回它，且从不触碰引导程序。
在该版本被映射之前，安装无法使用该转储中的编解码器，因此安装器会提议把转储发送给 RadioFoundry 团队进行映射，
并改为要求受支持的制造商固件文件。

备份就是那个 `.zip` 文件本身，文件名由电台型号、`_Backup_` 和日期组成，而不是其中的某个文件。
解压后又重新打包的备份仍然可以恢复（macOS 会自动解压下载的文件）。选择的文件不是备份时，恢复会说明它是什么，以及应选择什么。
原厂固件文件会进入原厂固件的恢复流程，前提是电台无需备份即可支持。

如果备份包含原厂固件的电台频率，请在[电台频率编辑器](04-programming.md#the-codeplug-editor)中打开该文件。
它会把信道、区域和联系人转换为 RadioFoundry 布局。

## Windows：引导程序驱动

对于通过 USB 刷写的电台，Windows 没有其 USB 引导程序的驱动，因此在你安装驱动之前，网页安装器和 rfoundry 都无法打开引导程序。
每台电脑用 Zadig 做一次即可：

1. 从 [zadig.akeo.ie](https://zadig.akeo.ie) 下载 Zadig 并运行。它无需安装。
2. 把电台置于引导程序并插上。你的电台的按键见[电台参考](23-radios.md)中它的一节。
3. 在 Zadig 的列表中选择 **Digital Radio in USB mode**。USB ID 框显示 `0483` `DF11`。如果未列出，
   选择 **Options > List All Devices**。
4. 在绿色箭头右侧选择 **WinUSB** 作为驱动，然后点击 **Install Driver**（或 **Replace Driver**）。等待 Zadig 提示成功。
5. 拔下电台，重新置于引导程序并再次连接。

只有引导程序需要这个驱动。电台运行 RadioFoundry 后，其串口无需驱动即可工作。

制造商的升级工具和 CPS 使用相同的 USB ID，需要装回它们自己的驱动。要恢复该驱动，在设备管理器中卸载该设备，
并勾选**删除此设备的驱动程序软件**，然后重新插入电台。

## 用安装包从命令行安装

网页安装器无法安装时，会提供**手动安装包**：一个 `.zip` 文件，包含在这台电脑的终端中用 rfoundry 安装你所选固件所需的一切。
照常选择和构建固件；之后的工作由安装包完成。

| 安装器在以下情况提供安装包 | 位置 |
|---|---|
| 浏览器没有 WebUSB 或 Web Serial（Safari、Firefox） | 起始页会说明。需要电台的步骤改为显示安装包，并提供原厂固件文件的选择器 |
| 连接引导程序或写入失败 | 错误信息下方的一行 |
| 电台在三分钟内未应答线缆，或准备电台失败 | 错误信息下方的一行 |

| 安装包内容 | 说明 |
|---|---|
| `README.txt` | 在 Windows、macOS 和 Linux 上的准备（Python、引导程序驱动、串口）、如何让电台进入更新模式，以及检查（`--dry-run`）和安装的命令，文件名已填好 |
| `firmware/` | 镜像及其清单 |
| `stock/` | 你提供的原厂固件文件（如有）。否则 README 会说明应放入哪个文件 |
| `rfoundry.py`、`tools/`、`stub/`、`requirements.txt` | 与网页安装器同一版本的 rfoundry。它从该文件夹运行；`pip` 把它的依赖装进虚拟环境 |

安装包需要 Python 3.8 或更高版本。它的 README 说明如何在各系统上安装 Python 和 rfoundry 的依赖，
以及 Windows 和 Linux 上 USB 引导程序需要哪种驱动。安装包由浏览器生成，不会上传任何内容。
rfoundry 无法安装的电台不会得到安装包：请在电脑上使用 Chrome 或 Edge。[电台参考](23-radios.md)中你的电台一节会说明它的安装方式。

## 进阶：命令行 rfoundry

每个发行版都附带 **rfoundry**，每个系统一个文件，名为 `rfoundry-<version>-<system>`。一次典型的安装和之后的更新如下：

```sh
rfoundry flash --release latest --stock STOCK.bin   # first install, with your original firmware file
rfoundry flash --release latest                     # update a radio that runs RadioFoundry
```

rfoundry 下载发行版、校验它、决定保留还是写入编解码器，并在写入前打印计划。`--dry-run` 只显示计划，不触碰电台。
有些电台有一个镜像无法覆盖的硬件版本，例如 UHF 板和 VHF 板。rfoundry 根据运行 RadioFoundry 的电台报告的内容选择镜像。
否则它会询问，或接受 `--option BAND=vhf`。各系统上的一次性设置、选项和编解码器选择，见 [rfoundry](../../tools/rfoundry/README.md)。
要构建并刷写你自己的镜像，见[构建](../dev/building.md)。

## 出问题时

引导程序位于安装器从不擦除的闪存区域，因此你总能重新开始：把电台置于引导程序并重新安装。刷写后屏幕一直黑屏时，也这样做。
安装器的每种错误及其解决方法，见[故障排查](20-troubleshooting.md#installing)。要把出错的情况发送给开发者，
使用**报告问题**，见[报告问题](20-troubleshooting.md#reporting-a-problem)。

## 回到原厂固件

[电台参考](23-radios.md)中你的电台一节会说明适用以下哪种方式。

1. 把电台置于引导程序。
2. 用以下方式之一写入原厂固件：

   - 在网页安装器中选择**恢复**。载入安装器在首次安装前所做的备份，并选择原厂固件。没有该备份时，
     载入制造商的固件文件（适用于你的电台的任意版本）。
   - 运行制造商的固件升级工具，并载入原厂固件文件。
3. 用制造商的 CPS 写入你的电台频率备份。原厂固件无法读取 RadioFoundry 使用过的电台频率。

在通过编程线安装的电台上，恢复只写入电台存储器中与备份不同的部分。完成时，它会说明写入了多少部分、有多少部分已经一致。
电台中的编解码器与备份中的一致时，安装器会说明它没有写入编解码器区域。
