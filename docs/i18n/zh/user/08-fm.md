# FM

FM 在每款电台上都可用。无法发送双音多频或检测亚音的电台，见[功能矩阵](../feature-matrix.md)。

## FM 信道上的快速设置

在主屏幕上按 **\***。磁贴按键盘布局排列。数字键作用于对应的磁贴。

<img src="../ux/screens/160x120i5/quick_fm.png" width="200" alt="FM 信道上的快速设置">

| 按键 | 磁贴 | 作用 |
|---|---|---|
| **1** | 功率 | 在电台的最低级别、默认级别和最高级别之间步进（[功率级别](16-battery-and-power.md#transmit-power)） |
| **2** | 静噪 | 打开静噪编辑器 |
| **3** | 亚音 | 打开亚音编辑器 |
| **4** | 到 VFO | 把信道复制到 VFO（[到 VFO](#to-vfo)） |
| **5** | 监听 | 保持静噪打开，或再次关闭。在 VFO 中此磁贴为发射频率（[异频](07-channels-zones-vfo.md#split-repeater-offset)） |
| **6** | VOX | 打开或关闭声控发射 |
| **7** | 双守 | 打开或关闭双守候 |
| **8** | 宽度 | 带宽 12.5 或 25 kHz（VFO 中也可用） |
| **9** | 亮度 | 打开亮度编辑器 |
| **0** | | 打开设置 |

**上** 和 **下** 在磁贴之间移动。**OK** 作用于焦点所在的磁贴。要关闭，按 **\*** 或 **返回**。所有更改都是临时的。
要把更改保存到信道，长按 **OK**。

在有**功率级别**键的电台上，该键在主屏幕上也会切换功率，每按一次切换一级，遍历电台的所有级别。

## 静噪

1. 按 **\***，然后按 **2**。静噪编辑器打开。
2. 按 **上** 或 **下**，或按 **0** 到 **9** 的数字键。更改即时生效，因此你能听到效果。
3. 要关闭，按 **OK**、**\*** 或 **返回**。

静噪级别在主屏幕上显示为“SQ”加数字。全机默认值在**设置 > 通话与收听 > 默认静噪**中（默认为 5）。

<img src="../ux/screens/160x120i5/quick_fm_squelch.png" width="200" alt="编辑静噪">

## 监听

- 长按**监听**，在按住期间打开静噪。状态行显示 RX 和 MON，LED 为绿色。
- **\***、**5** 保持监听打开，直到你再次用 **\***、**5** 关闭。

## 亚音（CTCSS 与 DCS）

1. 按 **\***，然后按 **3**。亚音编辑器在发射亚音上打开。电台显示“上下键选亚音  # 收发”。
2. 要在 CTCSS 亚音和 DCS 码之间步进，按 **上** 或 **下**。更改即时生效。
3. 要选择编辑哪个亚音，按 **#**：收发两者、仅发射或仅接收。收发亚音相同时，编辑器从“两者”开始。
4. 要关闭，按 **OK** 或 **\***。

使用 DCS 码时，松开 **PTT** 后电台继续发射 0.3 秒，并发送 DCS 关闭音。设为同一码的电台据此关闭静噪，因此不会在末尾听到噪声爆音。

主屏幕把亚音显示为标签，例如“T100.0”。

| 标签 | 含义 |
|---|---|
| T | 发射亚音与接收亚音不同 |
| R | 只有接收亚音，没有发射亚音 |
| 无亚音 | 没有亚音 |

## 带宽

**\***、**8** 在 12.5 和 25 kHz 之间切换。主屏幕显示“12.5k”或“25k”。

## 到 VFO

**\***、**4** 把信道复制到 VFO 并打开 VFO（“已复制到 VFO”）。信道没有临时的模式更改。要以 DMR 试用某个频率，
把它复制到 VFO，再在那里切换 VFO 的模式（[VFO](07-channels-zones-vfo.md#copy-a-channel-to-the-vfo)）。

## VOX

**\***、**6** 为 FM 信道打开 VOX（“VOX 开：说话即发射”）。你说话时电台发射，停止说话 1.5 秒后停止发射。接收到的音频从不触发它，
**PTT** 照常工作。灵敏度没有菜单项。哪些电台有 VOX，见[功能矩阵](../feature-matrix.md)。

## 忙信道锁定、确认音与突发音

电台核心有忙信道锁定和确认音（roger beep）；开发者通过调试链路设置它们。用于中继接入的 1750 Hz 突发音有一个侧键功能
（**突发音**，[设置](17-settings.md)）和一个每信道设置：在信道的设置中打开**突发音**后
（[编辑信道](07-channels-zones-vfo.md#editing-a-channel)），在该信道上每次按 PTT 都先发送 1 秒 1750 Hz，然后才接通麦克风。

## 发射超时

达到发射超时后，电台停止发射并显示“已达发射超时”。电台频率中信道自己的超时优先。它为 0 时，使用
**设置 > 通话与收听 > 发射超时**（默认为 3 分钟）。超时前 10 秒会响起警告音。

## 双音多频（DTMF）

在 FM 信道上按住 **PTT**，并按 **0** 到 **9**、**\*** 或 **#**：电台在你按住该键期间发送其双音多频，快速点按时至少发送 0.1 秒。
音调播放期间麦克风静音。快速连续按下的键各自发送自己的音调，中间有短暂间隔。发射屏幕的第二行显示“DTMF”和最后发送的数字。

- 有额外键盘键的电台可以发送 A 到 D（[电台参考](23-radios.md)）。
- 按键锁定时不发送任何内容。
- 在 DMR 信道上，发射期间按键无作用。
- 在 1750 Hz 突发音或确认音期间，按键无作用。
- 电台自行发射时（APRS 信标），或拒绝发射时（“NO TX”），按键照常工作。
