# APRS

APRS（自动分组报告系统）把你的位置分享给其他业余台站和 aprs.fi 等地图。电台以两种方式发送 APRS：

- **在 FM 上**：作为 1200 波特 AFSK 分组，发到你所在区域的 APRS 频率。电台会离开你的信道约一秒，发送后返回。
- **经 DMR**：作为位置报告发往 APRS 网关 ID（默认是 BrandMeister 的 5057）。这需要 DMR 信道。

并非每款电台两种都支持。有些只能发送，有些尚不能在 FM 上发送 APRS，构建也可能因 flash 空间而省去 APRS。[电台参考](23-radios.md)列出这些情况，并说明 APRS 在哪里已验证。

## 开始之前

- 你需要业余无线电执照。APRS 只在业余频率上发送，电台会拒绝其他频率。
- 你的呼号是电台名的第一个词（设置 > 我的电台，或电台频率中的电台名）。没有有效呼号时不会发送，APRS 页面会说明原因。
- 发送默认关闭，直到你开启。“立即发送位置”随时可用。

## APRS 页面

按 **OK**、**6**（工具）、**8**（APRS）。页面顶部显示你的呼号、APRS 频率、你的位置及其来源，以及下一个信标的发送时间。电台无法发送时会说明原因。

| 行 | 作用 |
|---|---|
| 立即发送位置 | 立即发送一次位置 |
| 自动信标 | 开：位置会自动发出（见触发条件） |
| 频率 | 你所在区域：北美 144.390、欧洲 144.800、澳大利亚 145.175、新西兰 144.575、日本 144.660、中国 144.640 MHz，或自定义（`tools/rfoundry_debug.py aprs set region custom`，然后 `aprs set freq_hz 144390000`） |
| 功率 | 随信道：APRS 使用电台当前功率级别。或单独选择级别，例如为附近的数字中继选低功率。无法通过空中发送 APRS 的电台此项变暗 |
| 路径 | 数字中继转发你的分组多远：无、WIDE1-1、WIDE1-1,WIDE2-1（默认）、WIDE2-1 或 WIDE2-2。见下文“路径”。无法通过空中发送 APRS 的电台此项变暗 |
| 间隔 | 发送频率：关、1、2、5、10 或 30 分钟 |
| SmartBeaconing | 移动快时更频繁，转弯后立即发送，静止时很少发送 |
| 发送方式 | AFSK（在 FM 上）、DMR，或两者 |
| 位置 | 位置来源，以及固定位置（见下文“位置”） |
| DMR 呼叫中的位置 | 在你的 DMR 语音呼叫中携带位置（见 [DMR](09-dmr.md#position-in-calls)） |
| USB 上的 KISS | 电台作为 KISS TNC 供电脑上的 APRS 程序使用 |
| 收到的台站 | 电台听到的台站（能接收 APRS 的电台） |

符号、注释和 DMR 目的地目前通过调试工具设置（`tools/rfoundry_debug.py aprs set ...`），以后可通过 qdmr 设置。

## 路径

路径说明分组在 FM 上可经过多少数字中继跳。每个 **WIDEn-N** 项允许多 N 跳。在“路径”上按 **OK** 步进到下一个选择。

| 路径 | 跳数 | 适用 |
|---|---|---|
| 无 | 0 | 只有直接听到你的台站（附近的 iGate） |
| WIDE1-1 | 1 | 补隙数字中继或一个广域数字中继 |
| WIDE1-1,WIDE2-1 | 2 | 北美和欧洲大部分地区的移动与手持使用（默认） |
| WIDE2-1 | 1 | 能直接到达广域数字中继的固定台站 |
| WIDE2-2 | 2 | 稀疏地区；跳过补隙数字中继 |

跳数越多，在繁忙频率上产生的副本越多。请使用能到达 iGate 的最少跳数。路径不适用于经 DMR 发送的位置。

路径也保存在电台频率的第一个 APRS 配置中，由 qdmr 编辑。在电台上更改也会写入那里；用不同路径写入电台频率会改变电台的设置。以最后更改的为准。

## 接收

在能接收 APRS 的电台上，电台会在你收听 APRS 频率时解码分组。在 **频率** 所示频率（你所在区域的，北美为 144.390 MHz）上建一个 FM 信道，或把 VFO 调到那里，并让电台停留在该信道。若分组在其他频率上发送，请先把**频率**设为自定义并输入该频率。听到的台站会进入**收到的台站**，发给你的呼号的消息会被保留并确认，数字中继（若你开启）会转发分组。

- 它只在 APRS 频率上以 FM 收听，且调谐频率必须与 APRS **频率** 完全一致。其他信道上不会解码任何内容。
- 音量旋钮无关紧要：完全关小音量的电台仍能解码。
- 在只解码能打开静噪的分组的电台上（[电台参考](23-radios.md)），分组必须强到足以打开静噪。请把静噪保持在通常级别，不要收得太紧。
- 电台收听 APRS 时会暂停省电：休眠的接收机会漏掉分组。
- 接收默认开启。可用 `tools/rfoundry_debug.py aprs set rx 0` 关闭。

## 触发条件

自动信标按间隔发出，或在 SmartBeaconing 下按速度和转弯发出。间隔绝不短于 30 秒。电台发送前会等待 APRS 频率空闲，10 秒后放弃。按下 PTT 总是优先：正在进行的 APRS 发送会停止，你的信道会回来。

## 位置

位置来自：

- **GPS**：在有 GPS 的电台上（[电台参考](23-radios.md)）。
- **电脑**：电脑上 GPS 的 NMEA，由 `tools/aprs_gate.py --nmea <GPS 端口>` 经 USB 发送（必须开启 USB 上的 KISS）。
- **固定**：你输入的位置。

自动会取最新的 GPS 位置，否则取电脑的，再否则取固定位置。

APRS > 位置有三行：**来源**（按 OK 在自动、GPS、电脑、固定间步进）、**纬度** 和 **经度**。设置固定位置：

1. 选择纬度并按 OK。数值打开以便编辑。
2. 用数字输入度数，包括小数位：`3`、`3`、`7`、`4`、`9`、`0` 是 33.7490。小数点已经在那里。经度小数点前有三位：84.3880 是 `8`、`4`、`3`、`8`、`8`、`0`（电台会为你补前导 0），122.4194 是 `1`、`2`、`2`、`4`、`1`、`9`、`4`。10 到 19 度时请自己输入 0。
3. 按上或下（或转动旋钮）在 N 与 S、E 与 W 之间切换。西经为 W。
4. 按 OK 保存。未输入的位置按零计算。BACK 删除最后一位；未输入任何内容时，关闭数值且不做更改。

四位小数可精确到约 11 米。你也可以在主屏幕输入“latitude”或“position”找到该页面。

## GPS 状态

**工具 > 位置**分四页显示电台 GPS 的状态。按上或下（或转动旋钮）到下一页，或按 1 到 4。屏幕较高的电台上，状态页还会显示网格定位和度分秒，因此只有三页。

| 页 | 显示内容 |
|---|---|
| 1 状态 | 3D 定位、2D 定位（接收机不说明时显示“定位”）或搜索中；使用和看到的卫星；位置、海拔、速度、HDOP（精度：好、一般、差）以及定位的 UTC 时间 |
| 2 星空 | 每颗卫星的位置：外圈为地平线，中圈为仰角 45 度，上方为北。实心点表示用于定位。颜色和图例表示系统：GPS、GLONASS、Galileo、北斗、QZSS |
| 3 信号 | 每颗卫星的信号强度条；实心条表示用于定位 |
| 4 网格 | 你的梅登黑德网格定位（FN42li），以及度分秒位置 |

“无 GPS 或已关闭”表示电台没有 GPS，或**设置 > 位置 > GPS** 已关闭。户外首次定位需要几秒到几分钟；室内可能无法定位。

## 配合电脑（KISS 与 iGate）

开启 **USB 上的 KISS**，然后运行 `tools/aprs_gate.py --port <电台端口>`：

- `--kiss-tcp 8001`：APRS 程序（APRSdroid、Xastir、YAAC）连接 TCP 端口 8001 并经电台发送。电台只发送来自你自己呼号的分组，在三连发之后每 10 秒最多一个。
- `--call <你的呼号>`：连接 APRS-IS。能接收 APRS 的电台此时成为 iGate，把它听到的内容传给 APRS-IS。若你允许，它也会把 APRS-IS 的消息回传到空中的本地台站。
- 在 USB 网络模式下使用 `--port udp:<电台地址>`。

电台不能同时处于热点模式。

在 USB 网络模式下，电台无需辅助程序即可完成两件事。APRS 程序直接连接电台地址的 TCP 端口 8001（[电台上的服务](15-usb-network.md#services-on-the-radio)）。电台自己登录 APRS-IS 服务器（[电台自身连接 APRS-IS](15-usb-network.md#aprs-is-from-the-radio)）。两者都需要开启 USB 上的 KISS。
