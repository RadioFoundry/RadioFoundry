# APRS

APRS（自动分组报告系统）把你的位置分享给其他业余台站以及 aprs.fi 等地图。电台以两种方式发送 APRS：

- **在 FM 上**：作为 1200 波特 AFSK 分组，发到你所在地区的 APRS 频率。电台离开你的信道约一秒，发送后返回。
- **经 DMR**：在 DMR 信道上，作为位置报告发往 APRS 网关 ID。默认为 BrandMeister 的 310999。它在任何主服务器上都可用，
  但在可能的情况下，请使用你自己主服务器的 MCC 加 999，例如 204999。BrandMeister 把 Motorola（LRRP）和 Hytera 位置报告转发到 APRS，
  因此请保留默认的 LRRP 格式（而不是 UDT）。已保存过 APRS 设置的电台会保留其存储的 ID：运行 `aprs set dmr_dst 310999`（美国）
  或 `aprs set dmr_dst <MCC>999`。位置在 APRS-IS 上显示为你的呼号，带有你的 BrandMeister 资料中的 SSID（aprs.fi 可能需要一分钟才显示）。

并非每款电台两种方式都支持。有些只能发送，有些不能在 FM 上发送 APRS，构建也可能为节省闪存空间而省去 APRS。
[功能矩阵](../feature-matrix.md)列出了这些情况。

## 开始之前

- 你需要业余无线电执照。APRS 只在业余频率上发送，电台会拒绝其他频率。
- 你的呼号是电台名称的第一个词（**设置 > 我的电台**，或电台频率中的电台名称）。没有有效呼号时，电台不发送任何内容，APRS 页面会说明原因。
- 在你打开发送之前，发送是关闭的。**立即发送位置**随时可用。

## APRS 页面

按 **OK**、**6**（工具）、**8**（APRS）。页面顶部显示你的呼号、APRS 频率、你的位置及其来源，以及下一个信标何时发出。
电台无法发送时会说明原因。

| 行 | 作用 |
|---|---|
| 立即发送位置 | 立即发送一次位置 |
| 自动信标 | 开：位置自动发出（见“触发条件”） |
| 频率 | 你所在的地区：北美 144.390、欧洲 144.800、澳大利亚 145.175、新西兰 144.575、日本 144.660、中国 144.640 MHz，或自定义（`tools/rfoundry_debug.py aprs set region custom`，然后 `aprs set freq_hz 144390000`） |
| 功率 | 按信道：APRS 以电台当前的功率级别发射。也可以单独选择一个级别，例如为附近的数字中继选择低功率。在无法通过空中发送 APRS 的电台上为灰色 |
| 路径 | 数字中继把你的分组转发多远：无、WIDE1-1、WIDE1-1,WIDE2-1（默认）、WIDE2-1 或 WIDE2-2。见下文“路径”。在无法通过空中发送 APRS 的电台上为灰色 |
| 间隔 | 发送频率：关、1、2、5、10 或 30 分钟 |
| 智能信标 | 快速移动时更频繁，转弯后立即发送，静止时很少发送 |
| 发送方式 | AFSK（在 FM 上）、DMR，或两者 |
| USB KISS | 电台作为 KISS TNC，供电脑上的 APRS 程序使用 |
| 收到的台站 | 电台听到的台站（能接收 APRS 的电台），最新的在前。发送了位置的台站显示其距离和相对你的方向（电台也有位置时）；这时该行的时间是该位置的时间。其他行显示最后听到该台站的时间。台站发送的对象和项目不算作其位置，超过一天的位置会被丢弃。选择一个台站并选择“消息”以填入其呼号 |
| SSID | 呼号后面的数字（`N0ABC-9`）：0 到 15，默认为 7。**OK** 增加，长按 **OK** 减少；0 只发送呼号。见下文“SSID”。在无法通过空中发送 APRS 的电台上为灰色 |

只以一种方式发送 APRS 的固件构建只显示该方式的行。只有经 DMR 的 APRS 时，没有频率、功率、路径、发送方式、收到的台站或 SSID，
USB KISS 改称 USB NMEA（电脑仍可向电台提供位置）。

用调试工具设置符号、注释和 DMR 目的地（`tools/rfoundry_debug.py aprs set ...`）。

## 台站详情

打开**收到的台站**，选择一个呼号并按 **OK**。**消息**排在第一；再按 OK 打开发往该台站的消息。收到的分组重新排列收到列表时，
选择仍停在同一个呼号上。

用 **上 / 下** 滚动，可查看距离和方向（两个位置都已知时）、听到该台站的时间、**直接**或**经中继**，以及与最后一个分组时间不同时的位置时间。
速度（km/h）和移动方位只在所保留的位置已知它们时显示。其余行显示符号的表和代码、所保留的注释或状态，以及分组数。
电台最多保留 23 个文字字符加结束标记；更长的注释不完整。不保留数字中继的名称。

如果该台站离开了收到列表，页面显示**已不在列表**。你仍可选择“消息”发往该呼号。

## 路径

路径说明分组在 FM 上可经过多少次数字中继转发。每个 **WIDEn-N** 条目允许再转发 N 次。在“路径”上按 **OK** 切换到下一个选项。

| 路径 | 跳数 | 适用场合 |
|---|---|---|
| 无 | 0 | 只给直接听到你的台站（附近有 iGate） |
| WIDE1-1 | 1 | 一个补点数字中继或一个广域数字中继 |
| WIDE1-1,WIDE2-1 | 2 | 北美和欧洲大部分地区的车载和手持使用（默认） |
| WIDE2-1 | 1 | 能直接到达广域数字中继的固定台站 |
| WIDE2-2 | 2 | 台站稀少的地区；跳过补点数字中继 |

跳数越多，繁忙频率上的副本就越多。使用能到达 iGate 的最少跳数。路径不适用于经 DMR 发送的位置。

路径也保存在电台频率的第一个 APRS 配置中，qdmr 可以编辑它。在电台上的更改也会写到那里，而以不同路径写入的电台频率会更改电台的路径。
使用最后更改的那个。

## SSID

SSID 在 APRS 上区分你的各个台站：同一呼号的车台和手台需要不同的 SSID（车台通常为 9，手台通常为 7）。
它适用于在 FM 上发送的分组；经 DMR 发送的位置带有 BrandMeister 上为你的 ID 设置的 SSID。

与路径一样，SSID 也保存在电台频率的第一个 APRS 配置中。在 APRS 页面或电台频率中设置它：在电台上的更改会写入电台频率，
而以不同 SSID 写入的电台频率会更改电台的 SSID。使用最后更改的那个。只有第一个 APRS 配置有效。固件更新后，
第一次不会采用电台频率中为 0 的 SSID：电台保留自己的值（默认为 7）。要不带 SSID 发送，在电台上设为 0。

## 接收

在能接收 APRS 的电台上，你在 APRS 频率上收听时，电台会解码分组。在 APRS 页面**频率**所示的频率（你所在地区的频率，
北美为 144.390 MHz）上新建一个 FM 信道，或把 VFO 调到那里，并让电台停留在该频率上。如果分组在其他频率上发送，
先把**频率**设为自定义并输入该频率。听到的台站进入**收到的台站**，发给你的呼号的消息显示在**消息**中并被确认，
数字中继（如果你打开了）会转发分组。来自互联网台站的消息（例如 APRS 消息服务）经附近的 iGate 到达你这里。
它们显示在发送方的呼号下，确认会发回给该发送方。

- 它只在 APRS 频率上以 FM 收听，且调谐的频率必须与 APRS **频率**完全相同。在其他 FM 信道上不解码任何内容。
- 音量旋钮无关紧要：音量调到最低的电台仍会解码。
- 在只解码能打开静噪的信号的电台上（[电台参考](23-radios.md)），分组必须强到足以打开静噪。让静噪保持通常的级别，不要调得太紧。
- 电台收听 APRS 时省电暂停：休眠的接收机会错过分组。
- 接收默认打开。用 `tools/rfoundry_debug.py aprs set rx 0` 关闭它（仅 FM）。

在 DMR 信道上，其他电台发送的 DMR APRS 位置（有些品牌以 NMEA 位置发送）无论发往谁，也会进入**收到的台站**：
通常发往 APRS 网关，与 FM 上一样，每个听到的台站都会列出。其 DMR ID 在电台的 DMR ID 数据库中时，它列在发送方的呼号下，
否则列在 DMR ID 下。无论接收设置如何都会这样。**收到的台站**显示台站及听到它的时间，而不显示其位置。

## 触发条件

自动信标按间隔发出，或在使用智能信标时根据速度和转弯发出。发送间隔从不短于 30 秒。电台等待 APRS 频率空闲后再发送，
10 秒后放弃。按 **PTT** 始终优先：正在进行的 APRS 发射会停止，你的信道恢复。

FM 信标可能打断双守候。它始终在你设置的 APRS 频率上发送，然后双守候在它原来收听的信道上恢复。A 或 B 的选择仍决定 **PTT** 在哪里发射；
它不决定信标频率。区域或 VFO 扫描会把信标推迟到扫描停止。

## 位置

位置来自：

- **GPS**：在有 GPS 的电台上（[电台参考](23-radios.md)）。
- **电脑**：电脑上 GPS 的 NMEA，由 `tools/aprs_gate.py --nmea <GPS port>` 通过 USB 发送（必须打开 USB KISS）。
- **固定**：你输入的位置。

自动依次采用新的 GPS 位置、电脑的位置、固定位置。

位置不只用于 APRS：DMR 呼叫和位置请求（LRRP）使用同一个位置。其设置在**设置 > 位置**下：**位置来源**（自动、GPS、电脑、固定）
和**固定位置**（一个含**纬度**和**经度**的页面）。要设置固定位置：

1. 打开设置 > 位置 > 固定位置，选择纬度并按 OK。数值进入编辑状态。
2. 用数字键输入度数，包括小数位：`3`、`3`、`7`、`4`、`9`、`0` 为 33.7490。小数点已经在那里。经度的小数点前有三位：
   84.3880 为 `8`、`4`、`3`、`8`、`8`、`0`（电台会替你补上开头的 0），122.4194 为 `1`、`2`、`2`、`4`、`1`、`9`、`4`。
   对于 10 到 19 度，请自己输入 0。
3. 按上或下（或转动旋钮）在 N 和 S、或 E 和 W 之间切换。西经为 W。
4. 按 **OK** 保存。没有输入的位数按 0 计。**返回** 删除最后一位；没有输入任何内容时，它关闭该值且不做更改。

四位小数可把位置精确到约 11 米以内。你也可以在主屏幕上输入“latitude”或“fixed”找到该页面。

## GPS 状态

**工具 > 位置**分四页显示电台的 GPS 在做什么。按上或下（或转动旋钮）切换到下一页，或按 1 到 4。在屏幕较高的电台上，
状态页还显示网格定位和度分秒，因此只有三页。

| 页面 | 显示内容 |
|---|---|
| 1 状态 | 3D 定位、2D 定位（接收机不说明时为“定位”）或搜索中；已用和可见的卫星数；位置、海拔、速度、HDOP（精度：良好、一般、较差）和定位的 UTC 时间 |
| 2 天空 | 每颗卫星的位置：外圈为地平线，中圈为仰角 45 度，北在上方。实心点表示参与定位。颜色和图例表示系统：GPS、GLONASS、Galileo、BeiDou、QZSS |
| 3 信号 | 每颗卫星的信号强度，以条形显示；实心条表示参与定位 |
| 4 网格 | 你的梅登黑德网格定位（FN42li），以及以度分秒表示的位置 |

“无 GPS 或已关闭”表示电台没有 GPS，或**设置 > 位置 > GPS** 已关闭。在室外首次定位需要几秒到几分钟；在室内可能无法定位。

## 与电脑配合（KISS 与 iGate）

打开 **USB KISS**，然后运行 `tools/aprs_gate.py --port <radio port>`：

- `--kiss-tcp 8001`：APRS 程序（APRSdroid、Xastir、YAAC）连接到 TCP 端口 8001，并通过电台发送。电台只发送来自你自己呼号的分组，
  在连续三个之后最多每 10 秒一个。
- `--call <your call>`：连接到 APRS-IS。能接收 APRS 的电台随后成为 iGate。它把听到的内容转发到 APRS-IS。如果你允许，
  它还会把来自 APRS-IS 的消息重新在空中转发给本地台站。
- 在 USB 网络模式下，使用 `--port udp:<radio address>`。

电台不能同时处于热点模式。

在 USB 网络模式下，电台无需辅助程序即可完成这两项。APRS 程序直接连接到电台地址的 TCP 端口 8001
（[电台上的服务](15-usb-network.md#services-on-the-radio)）。电台自己登录 APRS-IS 服务器
（[从电台连接 APRS-IS](15-usb-network.md#aprs-is-from-the-radio)）。两者都必须打开 USB KISS。
