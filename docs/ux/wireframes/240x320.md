# 240x320 color (portrait)

30 columns x 26 rows of 8x12 px. UPPERCASE words are drawn in the 2x font (16x24). Example board: any 240x320 radio (DM-32 class if its panel is this size).

## Home, idle, DMR

```
┌──────────────────────────────┐
│ IDLE  DMR ▮▮▮▯  ⌖  ✉2   84%  │  status strip (row 1)
├──────────────────────────────┤
│ Zone: Local repeaters        │  place
│ 03  COUNTY DMR               │  channel, 2x font
│                              │
├──────────────────────────────┤
│ PTT →                        │  talk target
│ TG 3100  USA                 │  2x font
│ ┌────┐┌────┐┌────┐┌──────┐   │
│ │TS 1││CC 1││High││♦ Priv│   │  chips; privacy chip only when on
│ └────┘└────┘└────┘└──────┘   │
├──────────────────────────────┤
│ Last heard  · 2 min ago      │  activity (idle = last heard)
│ Joe Smith  K1ABC             │
│ TG 91 · TS1 · 12 km NE       │
│                              │
│                              │
│                              │
│                              │
│                              │
│                              │
├──────────────────────────────┤
│ OK Menu  * Quick  # Joe      │  hint row
└──────────────────────────────┘
```

Notes: the channel name and the talk target are the two biggest things (P5). The hint row names the last caller so the user learns that `#` acts on them.

If TX is refused, the same screen shows `CAN'T TRANSMIT` with the reason and what to do, with the error tone.

## Quick settings (DMR)

```
┌──────────────────────────────┐
│ IDLE  DMR ▮▮▮▯          84%  │
├──────────────────────────────┤
│ Quick · 03 County DMR        │
├─────────┬─────────┬──────────┤
│1 Power  │2 Slot   │3 Color   │
│  HIGH   │  TS 1   │  CC 1    │
├─────────┼─────────┼──────────┤
│4 Mode   │5 Hear   │6 Privacy │
│  → FM   │  all OFF│  OFF     │
├─────────┼─────────┼──────────┤
│7 Scan   │8 Talk to│9 Bright  │
│  OFF    │  TG 3100│  70%     │
├─────────┴─────────┴──────────┤
│ 0 All settings               │
├──────────────────────────────┤
│ 1-9 change  Hold OK save     │
└──────────────────────────────┘
```

The grid is the keypad: the tile under the `5` key is tile 5. Focused tile has a thick border; `NAV_UP`/`NAV_DOWN` move focus in reading order.
