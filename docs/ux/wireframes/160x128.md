# 160x128 color

20 columns x 10 rows of 8x12 px. UPPERCASE = 2x font (16x24, 10 characters per line). Example boards: DM-1701, MD-UV380, MD-9600.

## Home, idle, DMR

```
┌────────────────────┐
│IDLE DMR ▮▮▮ ✉2 84% │ status strip (8x8 font)
│Local repeaters     │ zone
│03 COUNTY D…        │ channel, 2x (middle-ellipsized)
│                    │
│PTT→ TG 3100        │ talk target, 2x-ish (12x16 font)
│USA  TS1 CC1 Hi     │ chips as text
│────────────────────│
│K1ABC Joe · TG91 2m │ last heard, one line
│OK Menu *Quick #Joe │ hint row
└────────────────────┘
```

## Quick settings

```
┌────────────────────┐
│Quick 03 County DMR │
├──────┬──────┬──────┤
│1Pwr  │2Slot │3CC   │
│ High │ TS1  │ 1    │
├──────┼──────┼──────┤
│4Mode │5All  │6Priv │
│ →FM  │ off  │ off  │
├──────┼──────┼──────┤
│7Scan │8TalkTo│9Brt │
│ off  │ 3100 │ 70%  │
└──────┴──────┴──────┘
```

Status strip is replaced by the title here because the TX/RX pill moves into the title row when RX/TX happens (`[RX] Quick…`), so the state stays visible (P2).
