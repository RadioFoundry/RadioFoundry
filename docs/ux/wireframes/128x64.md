# 128x64 monochrome

21 columns x 8 rows of 6x8 px. UPPERCASE = 2x height font (8x16, two rows, 16 characters). Example board: GD-77. No color: state is shown with inverse video and words, which is also what the color layouts guarantee (P5).

Inverse video is drawn as `▓text▓`.

## Home, idle, DMR

```
┌─────────────────────┐
│▓IDLE▓DMR ▮▮▮ ✉2 84% │ status strip; ✉2 = 2 unread
│03 COUNTY DMR        │ 2x (rows 2-3)
│                     │
│>TG 3100 USA         │ talk target, 2x (rows 4-5)
│                     │
│TS1 CC1 Hi           │ chips
│K1ABC TG91 2m        │ last heard
│OK Menu *Quick #Joe  │ hint row (can be turned off)
└─────────────────────┘
```

Large-text mode drops the chips, last heard and hint rows and uses the 2x font for both channel and talk target with room to spare.
